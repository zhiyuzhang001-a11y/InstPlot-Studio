# Lite ↔ Studio：单组数据往返编辑

## 操作

在 Studio 侧栏选中目标曲线，点击“在 Lite 编辑这组数据”。专用 Lite 窗口只载入该数据组，直接使用 Studio 当前 X/Y 列。处理、删点或新增处理列后，点击“发回 Studio”，再在 Studio 点击“更新这组数据”。不需要手动导出或寻找文件。

左侧选择与右侧曲线高亮同步。首次开启后，默认“切换曲线时自动同步 Lite”，选择另一条曲线即可更新同一个 Lite 窗口，无须关闭处理/拟合窗口。工具窗口保持打开，标题、目标和范围随新数据刷新；可在联动面板取消跟随。

切换前未发回的修改自动保存为本次私有会话草稿；切回同一曲线且 Studio 数据修订未变化时恢复草稿。界面提示草稿数量。草稿不是长期项目存储，请发回确认或自行导出后再关闭 Lite；最多32份/128MiB，达到限制则停止切换而不丢弃修改。Studio 撤销/重做不恢复旧修订草稿，避免旧值覆盖新基线。

默认按新数据自动确定受影响坐标范围，避免去背景等处理产生的负值被原手动范围裁掉。可明确勾选“固定原手动范围与刻度”保留旧范围；不受影响轴、颜色和排版保留。Lite 的当前 X/Y 可用于该目标曲线的新绑定；同文件其他数据组不会跟随改变。

Studio 保留颜色、线型、点样式、图例、布局和其他数据源；更新是一条可撤销/重做的编辑。源 CSV/Excel 不会被覆盖。原有拟合不会自动重算，确认窗口会提醒。手动测量、外部未嵌入数据和拟合数据本身不走此入口。

## 边界

两边都需支持 `INSTPLOT_STUDIO_EDIT_PROTOCOL_V2`。同一 Studio 会话复用专用 Lite 进程，确认后仍可继续处理、撤销和发回；Studio 的撤销/重做会把当前数据同步到同一 Lite 窗口，不复用旧回传。确认相同数据时保留 Lite 处理历史；Studio 改变数据基线或切换目标时重置 Lite 历史，避免在旧基线上继续处理。关闭 Lite 后，下次编辑才重新启动。普通独立打开的 Lite 窗口不被接管。

Studio 在启动前检查兼容性，避免旧 Lite 将未知参数当普通文件。保持 Studio 打开；关闭、换项目或结束联动会结束本次关联，但不会强杀 Lite。Lite 窗口中的结果仍可正常导出。

临时会话为私有、随机命名目录；`request.json` / `result.json` 及递增的 `request-N.json` / `result-N.json` 使用 schema 1、随机 session ID、目标数据组 ID 和原数据修订 SHA-256。每个修订不可变、只发布一次。无回调命令或任意输出路径；读取拒绝链接、未知字段、过大文件、无效数字/掩码、重复/缺失列和身份不符。Studio 在确认时再次检查源数据及绑定，已变化则拒绝覆盖。

传输使用双精度往返解析，不进行单位换算、归一化或隐式舍入。Lite 中主动执行的处理会改变数值；保留原手动范围时可能裁掉负值等新数据，确认面板提供“让坐标完整显示处理后的数据”。这只是视图范围，不是数据丢失。

原始列必须保留；新增列允许。数字、空单元掩码和 alive 删点状态一起传递。取消/失败不修改原图。临时副本不上传云端，不是项目的长期存储。

协议实现位于 Studio `lite_edit_protocol.rs` 与 Lite `studio_edit_protocol.rs`，必须保持同版字节一致。数值更新事务与 GUI/进程启动分离；不得借此修改 updater 信任、生产渠道或发布配置。
