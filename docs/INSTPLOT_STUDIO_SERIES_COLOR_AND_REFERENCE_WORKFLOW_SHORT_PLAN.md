# InstPlot Studio 系列颜色与参考线交互完善短计划

> 状态：`COMPLETED`
> 制定日期：2026-09-27
> 基线：当前 `codex/dual-axes` 分支已经完成双轴、参考线、测量箭头及独立 QA。
> 范围：统一逻辑系列颜色；完善参考线创建与移动；修正箭头端点几何；压缩轴模式选择器和测量箭头设置布局。
> 非目标：新增 artist 类型、改变数据导入格式、增加参考区域、发布 release 或执行 Windows 构建。

## 1. 固定产品规则

### 1.1 一组数据只有一个系列颜色

- 散点图、线图和点线图是同一逻辑系列的不同显示方式，不是不同数据对象。
- 图形类型切换必须保留原系列颜色，不得因为创建或删除 line/scatter artist 而重新取色。
- 点线图中的线、点、误差棒及其图例样例统一使用同一个系列颜色。
- 用户从线、点、误差棒或图例入口修改颜色时，实际执行的是逻辑系列颜色修改。
- 线宽、线型、marker 形状、marker 大小、marker 间隔、实心/空心和误差棒尺寸仍分别设置。
- 本阶段不提供线与点颜色解除联动，避免同一组数据产生含义不明的多颜色表达。

### 1.2 旧项目和异常状态

- 新项目和新建系列从创建开始满足系列颜色一致性。
- 对已有 line、scatter、error-bar 颜色不一致的逻辑系列，采用确定性主颜色：按
  `series_group.artist_ids` 顺序选择第一个可见 line/scatter 的颜色；若不存在，再取第一个
  error-bar 的颜色；仍不存在时使用当前 palette 的系列默认色。
- 规范化必须覆盖实际对象和图例，不允许只修复图例外观。
- 旧项目兼容处理必须可测试、可撤销或在载入迁移中有明确 provenance；不得静默丢失其他样式。

### 1.3 参考线默认单次创建

参考线工具采用“临时预览—精确设置—明确提交”流程：

1. 用户选择竖直/水平参考线及对应坐标轴；
2. 在绘图区点击，生成尚未写入 Project Document 的临时参考线；
3. 打开紧凑设置窗口，允许修改数值、轴绑定、颜色、线型、线宽及是否纳入自动范围；
4. 用户明确选择以下操作之一：
   - `添加`：提交当前参考线并结束本轮工具；
   - `添加并继续`：提交当前参考线并继续等待下一次画布点击；
   - `取消`：丢弃临时参考线并结束本轮工具。

关闭设置窗口、按 `Esc` 或切换到其他工具等同于“取消”当前临时参考线并结束本轮操作。
一次提交只产生一个可撤销步骤；临时预览不得污染保存、导出、Publication Check 或 dirty 状态。

### 1.4 已有参考线随时可移动

- 参考线工具激活时，空白区域点击用于创建；命中已有参考线时优先选择或拖动，不能再新增一条。
- 已有参考线显示抓取光标，空白绘图区显示创建光标。
- 新提交的参考线自动成为当前选中对象。
- 双击已有参考线仍打开正式属性窗口；拖动只修改位置并形成一个合并后的撤销步骤。

### 1.5 紧凑布局

- 顶栏轴模式下拉框使用能容纳“单轴 / 双 Y 轴 / 双 X 轴”最长文本的固定紧凑宽度，避免切换时跳动；目标宽度先按 `80–88 px` 验证。
- 普通文字标注的文字输入框、预览以及“斜体 / 下标 / 上标 / 正体 / 数学符号与希腊字母 / 输入帮助”工具栏本阶段保持现状，不纳入紧凑化修改。
- 测量箭头端点使用两行网格：

  ```text
  起点    X [          ]    Y [          ]
  终点    X [          ]    Y [          ]
  ```

- 方向约束、双端箭头、箭头头型、大小和线宽按同类属性组合成紧凑行；窄窗口允许整组响应式换行，不能退化为每个数值一行。
- 普通文字标注的每条连接线改为折叠式紧凑卡片；卡片标题显示“连接线 N”和删除入口，展开后按属性分组：

  ```text
  坐标轴 [X1 / Y1]    方向 [末端箭头]
  目标    X [       ]  Y [       ]
  箭头    [空心]      大小 [       ]
  线条    [颜色]      宽度 [       ]  线型 [       ]
  ```

- 多条连接线各自保持独立折叠状态；新增连接线只展开新卡片，不强制展开已有卡片。
- 连接线卡片在窄窗口中按“整组”换行，不能退化为坐标轴、方向、头型、大小、颜色、线宽和线型各占一行。
- 参考线正式属性窗口和新的临时创建窗口复用同一紧凑字段组件，避免创建后与再次编辑出现两套排列。
- 小窗口审计结论：测量箭头与 annotation connector 属于必须修复的严重纵向堆叠；参考线属于随新流程一并整理的轻度问题。坐标轴范围、图尺寸、图例行列、线条基础样式、配色方案、Publication Check 和删除确认当前分组合理，不做无关压缩；error bar 的 cap、颜色和 stroke 仅三组，不列为本阶段缺陷。

### 1.6 箭头尖端必须等于数据端点

- 测量箭头和文字连接线的起点/终点表示箭头尖端位置，不是箭头头部与线身的连接位置。
- 实心箭头的三角形尖端必须精确落在对应数据端点；线身从三角形底边开始，不能继续画到尖端下方形成可见方头或穿出尖端。
- 双向箭头两端分别裁短线身；单向箭头只裁短带箭头的一端。
- 开放箭头的尖端也必须与数据端点一致，并与实心箭头遵守相同的方向约定。
- 水平、垂直、斜向、自由拖拽、连接线和测量箭头必须共用同一套端点几何规则。
- 当线段短于两个箭头头部所需长度时，必须采用确定性退化策略，不能产生反向线身、越过对端、NaN 或翻转箭头；首选按可用长度等比缩小头部并把线身压缩为零。
- 命中范围、选择高亮、拖拽手柄和导出边界必须包含真实尖端及完整箭头头部。

- 旧项目中 line/scatter 颜色不一致：按固定优先级规范化且其他样式不丢失。
- 参考线：添加、添加并继续、取消、关闭窗口、Esc、切换工具、Undo/Redo。

- 参考线工具激活时，拖动已有参考线不产生新对象。
- 轴模式下拉框三种文字均完整，箭头间距紧凑且切换不跳动。
- 测量箭头窗口在普通、最大化、全屏和窄窗口下均保持成组布局。
- 普通文字标注含零条、一条和多条连接线时，卡片折叠状态、对齐、删除和新增均正确；多条连接线不会使所有详细字段同时铺满窗口。

## 6. 后续一致性修订（已完成）

> 记录日期：2026-09-27
> 状态：`COMPLETED`
> 说明：以下是完成本短计划后的实机复查结果，不改变上方已完成阶段的历史结论；后续修改时应作为一个小型一致性修订批次处理。

### 6.1 参考线默认线型与设置名称必须一致

- 新建参考线当前以虚线绘制，但属性窗口可能把默认线型显示为“点划线”。
- 已确认原因是默认 dash 参数 `[4.0, 3.0]` 能被渲染层归类为虚线，却不能被设置界面的精确名称映射识别，最终错误回落为点划线。
- 后续应让参考线默认值使用统一的标准虚线定义，并让创建草稿、文档默认值、属性编辑器、保存重开和各导出后端共用同一来源，禁止分别硬编码。
- 既有项目中的非标准 `[4.0, 3.0]` 应采用明确的兼容或规范化策略，不能仅修改界面文字掩盖差异。
- 验收：新建、编辑、保存重开及 PDF/SVG/PNG 中均显示虚线，属性窗口选中项也必须为“虚线”。

### 6.2 所有小窗口的同排控件对齐审计

- 已确认参考线属性中的“线宽 / 线型”没有垂直居中，控件高度与文字基线不一致。
- 后续应建立统一的紧凑设置行或网格组件，固定标签列、控件高度、输入宽度、组间距和垂直居中；空间不足时按属性组整体换行，不能让同一组内部错位。
- 审计范围至少包括：参考线方向/数值/线条、测量箭头的箭头类型/大小/线宽/标签偏移、文字连接线的坐标轴/方向/目标/箭头/线条、主副刻度模式与间隔、录入数据的图形与误差类型，以及通用颜色和 stroke 编辑器。
- 配色方案、Publication Check、图例和文字输入工具栏也应纳入复查，但没有问题的区域不做无关重排；文字输入工具栏继续保持现状。
- 验收必须覆盖普通、最大化、全屏、窄窗口以及中文界面，检查同排居中、成组换行、截断和可操作性。

### 6.3 marker 间隔必须保留首尾标记，但不得改变曲线

- 当前 marker 仅按 `0, N, 2N ...` 的索引显示，因此首点一定显示，末点只有恰好落在间隔上才显示；曲线仍连接到最后一个数据点，视觉上会像是曲线超过最后一个 marker。
- 后续规则固定为：第一个有效点显示、中间按间隔显示、最后一个有效点显示；末点已经命中间隔时不得重复绘制。
- **marker 间隔只能控制点标记的显示密度。曲线始终使用全部有效数据点绘制，不得抽稀、重采样或改变曲线形状、平滑度、线宽、误差棒和命中数据。**
- “首尾”指经过缺失值、非有限值和对数轴非法值过滤后真正可绘制的首末有效点。映射阶段应保留原始数据索引，避免 marker、误差棒、tooltip 和数据命中在过滤后错位。
- 图例仍只使用一个代表性 marker，不受间隔和强制末点规则影响。
- 验收覆盖：点数整除/不整除间隔、单点、两点、间隔大于点数、缺失值、对数轴非法值、误差棒、纯散点和点线图；所有情况下曲线路径修改前后必须完全相同。

### 6.4 清空测量箭头标签不能关闭输入框

- 当前清空默认 `\Delta x` 后会立即执行“移除测量标签”，导致标签对象和输入框在下一帧消失。
- 输入框应允许暂时为空并继续编辑；空草稿不能自动等同于删除，也不能产生无意义的撤销记录。
- 只有用户明确点击“移除标签”时才删除标签。建议采用本地编辑草稿：有效非空内容才提交文档，暂时为空时保留窗口和对象生命周期。
- 验收覆盖：全选删除、逐字删除、删除后重新输入、失去焦点、关闭窗口、显式移除、Undo/Redo、保存重开以及普通/最大化/全屏窗口。

### 6.5 删除对象后必须同步关闭其编辑窗口

- 当前删除绘图对象时只清除画布选择，没有统一移除对应的 context editor target，因此会留下只显示“双击图中对象即可编辑”的空窗口。
- 删除事务应立即使所有指向该对象的编辑窗口和待置顶目标失效；窗口渲染前还必须防御性检查目标是否存在，不存在时直接关闭，不能显示空壳窗口。
- 该规则应覆盖从对象窗口、画布或其他入口删除，数据源级联删除、清除全部数据、项目替换以及 Undo/Redo。Undo 恢复对象时不要求自动重新打开之前的窗口。
- 验收：删除任意曲线、参考线、测量箭头、文字标注、连接线相关对象或其数据源后，不遗留空窗口，不误关其他对象窗口，也不留下无法置顶的失效目标。

### 6.6 空副轴的可见提示、自动更新与导出收口

- 单轴模式继续由 X1/Y1 拥有四侧边缘：顶部镜像 X1 刻度、右侧镜像 Y1 刻度，默认不重复显示顶部/右侧刻度数字和标签。
- 切换为双 Y 后，右侧边缘立即交给 Y2，Y1 的右侧镜像刻度停止绘制；切换为双 X 后，顶部边缘立即交给 X2，X1 的顶部镜像刻度停止绘制。主轴镜像刻度与独立副轴不得同时占用同一边缘。
- 副轴已经启用但尚无可见数据曲线时，不显示虚假的 `0–1` 数字刻度。编辑画布只显示清晰但克制的待设置状态：副轴 spine/交互入口以及灰色占位文字 `Y2 label` 或 `X2 label`。
- 占位文字只是 UI 提示，不是 Semantic Label，不写入 Project Document、不产生 dirty/Undo 记录、不参与布局内容边界，也不得进入 PDF、SVG、PNG 或项目导出。
- 仅仅单击或选中一条曲线不能改变轴绑定、范围或标签。用户把曲线明确改绑到 `X1/Y2` 或 `X2/Y1` 后，才立即更新副轴自动范围、数值刻度、命中区域和预览。
- 第一条可见曲线绑定到尚未使用的副轴时，如果该轴标签仍为空、为系统默认值或从未被用户编辑，软件可以根据可靠的列名和单位自动填入标签；用户手动编辑过的标签不得被后续曲线覆盖。无法可靠识别时保留明确的轴名提示并允许用户输入，不能猜测单位。
- 多条曲线绑定同一副轴时，新增曲线只触发范围和刻度重算；单位或语义冲突应给出警告，不得反复改写标签或自动换算数据。
- 删除、隐藏或改绑最后一条副轴可见曲线后，副轴回到待设置状态：清除数字刻度并恢复灰色占位提示，但不删除副轴配置、标签历史或休眠曲线绑定。
- 导出前使用统一 preflight 检查当前启用副轴是否没有任何有效可见曲线。遇到空 Y2/X2 时不得静默导出空副轴，显示原因明确的提示，并只提供：
  - `改为单轴并导出`：通过正式、可撤销的轴模式事务切回单轴，再继续本次导出；
  - `返回检查`：取消本次导出并保留当前双轴编辑状态。
- 执行“改为单轴并导出”后，占位文字和副轴立即消失，原副轴边缘归还主轴并恢复对称刻度；该操作不得删除数据、列绑定、用户标签或副轴外观设置。绑定副轴的休眠曲线继续保留且不迁移到主轴。
- 因为“改为单轴并导出”改变项目轴模式，它必须进入正常 Undo/Redo 和 dirty 状态；导出动作本身仍不修改数据文件。
- 空副轴判定以有效可见的数据曲线为准，不能把参考线、文字连接线、测量箭头、隐藏曲线或 UI 占位标签误算成有效数据。若副轴存在绑定但被用户隐藏的曲线，提示中应说明切回单轴后这些曲线仍将休眠，避免用户误以为数据被删除。
- 本节是对既有双轴设计中“无数据副轴不显示虚假刻度、边缘唯一所有权、返回单轴恢复镜像刻度、第一条曲线提供标签建议”的具体交互补充；不改变“曲线轴绑定必须由用户明确选择”和“关闭副轴只休眠、不迁移、不删除”的既定规则。
- 验收覆盖：单轴→空双 Y/双 X、第一条曲线改绑、继续添加同单位/冲突单位曲线、手动标签保护、删除/隐藏/改绑最后一条曲线、清除全部数据、保存重开、Undo/Redo，以及从菜单和快捷入口执行 PDF/SVG/PNG 导出。
