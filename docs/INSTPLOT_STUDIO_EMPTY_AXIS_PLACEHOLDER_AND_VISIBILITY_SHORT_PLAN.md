# InstPlot Studio 空副轴、轴显示与紧凑导出短计划

> 状态：`COMPLETED`
> 修订日期：2026-09-28
> 核心边界：**margin 自动收紧只发生在导出 PDF、SVG、PNG 时。编辑预览、画布尺寸、对象坐标和拖拽逻辑保持现状。**

## 1. 本阶段保留的功能

### 1.1 空副轴占位

- 双 X 或双 Y 开启但尚无曲线绑定副轴时，在编辑预览中显示灰色 `X2 label` / `Y2 label`。
- 占位字号与正式轴标签一致，间距至少为 `max(7 pt, label_tick_pad_pt)`。
- 占位不得覆盖 spine、图外图例或超出白色预览区域；必要时仅增加 UI-only gutter。
- 绑定第一条副轴曲线后占位消失；切回单轴后占位和 UI-only gutter 同帧消失。
- 占位不写入项目、不进入导出、不改变正式标签位置。

### 1.2 坐标轴显示窗口

- 选择工具下双击主图空白区域，打开或置顶“坐标轴显示”窗口；命中已有对象时仍优先编辑对象。
- 可按当前存在的 X1、Y1、X2、Y2 分别控制：轴线、刻度线、刻度数字、轴标签。
- 四项是 master visibility，只与原有精细设置相与，不覆盖 near/far、主/副刻度等原配置。
- 隐藏项不绘制、不命中，也不参与导出内容边界；重新显示后恢复原设置。
- v10 仅为保存 `AxisVisibilityRecord` 服务，不改变既有 `width_mm/height_mm` 的总画布含义。

## 2. 紧凑导出的唯一目标

- 仅在用户导出 PDF、SVG、PNG 时，根据实际可见内容生成独立的 tight export page。
- 编辑预览继续使用原来的正式画布大小；不得因为导出裁边而移动预览、改变滚动范围或改变命中坐标。
- 项目中的 `width_mm/height_mm`、图例坐标、标注坐标、轴标签间距和数据映射均保持原语义。
- 不引入 PlotSize/LegacyCanvas，不增加画布转换按钮，不迁移对象坐标。

### 2.1 导出边界规则

- 导出边界至少包含完整 axes rectangle，确保科学图的绘图区和数据映射不会因数据分布而被裁短。
- 在此基础上并入所有实际可见内容：spine、刻度、刻度数字、轴标签、曲线、marker、误差棒、图例、文字、连接线、测量箭头、参考线和图像。
- 边界计算必须考虑 clip、线宽、线帽、连接方式、marker 半径、误差棒 cap、箭头尖端、旋转文字和透明度。
- 完全位于活动 clip 外的内容不扩大导出页面；隐藏或全透明内容不参与边界。
- 最终边界统一向外保留 `3 pt` 安全距离，避免抗锯齿或描边被切掉。
- PDF、SVG、PNG 必须使用同一 export bounds 和同一次顶层 translation；PNG 像素尺寸向上取整。

## 3. 明确删除的过度设计

- 删除 `FigureSizingRecord::PlotSize / LegacyCanvas`。
- 删除旧画布转换预览、转换按钮及 Undo/Redo 命令。
- 删除 figure-point 标注和手动图例的 plot-local 坐标重基。
- 删除为画布转换引入的外部数据特殊恢复路径。
- 删除预览画布对 tight-export translation 的依赖；tight translation 只属于导出结果。

## 4. 验收标准

- 同一文档在开启或关闭 tight export 计算前后，编辑预览、axes bounds、对象命中和拖拽结果完全一致。
- 隐藏 tick、tick label 或 axis label 后，导出文件对应方向的外围空白缩小，但 axes rectangle 尺寸不变。
- 图外图例、负坐标标注、箭头尖端和粗描边完整可见，页面外围只剩约 `3 pt` 安全距离。
- PDF、SVG、PNG 的物理边界一致；透明与白底 PNG 内容位置一致。
- 旧项目继续按既有宽高和对象坐标打开，不出现转换提示。
- 完整测试、严格 Clippy、GUI 普通/最大化/全屏操作及独立 agent 验收全部通过后，才替换 Spotlight 应用。

## 5. 非目标

- 不改变预览画布 margin。
- 不重新定义图尺寸为纯绘图区尺寸。
- 不修改正式轴标签、刻度定位器或数据绑定。
- 不新增文件格式、四轴模式或 inset axes。
