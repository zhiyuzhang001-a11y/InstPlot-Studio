# InstPlot Studio 重构后真实操作验收计划

> 状态：READY FOR EXECUTION
> 日期：2026-09-26
> 被测对象：`$HOME/Applications/InstPlot Studio.app`
> 测试性质：真实用户操作与回归验收，不以代码审查或单元测试代替界面结果

## 1. 目标与通过门槛

本轮验证模块化重构没有破坏用户已能使用的功能，尤其关注跨模块闭环：导入、文档状态、
画布交互、编辑窗口、保存重开和导出是否仍然使用同一份数据与样式。

- P0：崩溃、无法导入/成图、数据丢失或错绑、项目损坏、导出失败。任一项出现即不通过。
- P1：核心入口失效、清空后不能重导、XY 选择不更新、窗口不可操作、图例/标注不能编辑或移动。
  任一项稳定复现即不通过。
- P2：对齐、留白、提示文字、视觉反馈等问题。必须记录，但不掩盖 P0/P1 结论。
- 只有实际完成操作并观察到结果才可写 PASS；自动测试只能作为补充证据。

## 2. 环境与证据

1. 从 Spotlight 启动唯一的 `InstPlot Studio`，记录应用路径、版本、构建号和图标。
2. 测试输出统一放在 `/tmp/instplot-studio-post-refactor-qa/`。
3. 每个失败记录：用例编号、窗口状态、步骤、实际/预期结果、复现次数和截图。
4. 当前测试内容无需保存；若测试进程阻塞或崩溃，可以直接退出并重新打开。
5. 窗口状态分别为普通窗口、macOS Zoom 最大化、macOS 原生全屏；三者不可互相代替。

## 3. 第一阶段：核心数据闭环（最高优先级）

### R01 首次导入与自动成图

导入
`$HOME/Library/Mobile Documents/com~apple~CloudDocs/E-dsk_1_5V.csv`。

预期：示例被替换；自动选择合理 X/Y 列并立即成图；文件名成为初始图例；坐标范围完整包含数据；
左栏出现紧凑文件卡片，删除按钮可用。

### R02 清空、删除与再次导入

先删除唯一文件，再导入同一文件；随后执行“清空全部”，再导入同一文件。

预期：两次均能完整成图；坐标自动重新适配；旧曲线、旧标签、旧 ticks、旧图例和旧选择状态不残留；
清空后回到明确的默认文档状态。

### R03 多文件与多系列

连续导入 `E-dsk_1_5V.csv`、`E-dsk_0V.csv`、`E-dsk_0_5V.csv`、`E-dsk_1_0V.csv`。

预期：每个文件各有一组 X/Y 控件；每条曲线颜色和点形均可区分；图例顺序与文件顺序一致；
删除中间文件只删除对应系列；其余绑定、颜色和坐标范围正确。

### R04 XY 列与绘图类型

在至少两个文件卡片中分别更换 X、Y 列，并把绘图类型依次改为散点、曲线、点线图。

预期：选择后立即更新且不关闭/跳走界面；不同文件互不串改；图例示例准确反映纯点、纯线或点线组合。

### R05 格式兼容与错误反馈

真实操作导入 CSV、TSV/TXT/DAT 和 XLSX；补充测试数字表头、缺失值和多数据源夹具。

预期：合法内容自动解析并成图；缺失值形成合理断点；无法识别时给出中文、可行动的错误，不能静默失败。

## 4. 第二阶段：坐标、文本、曲线与误差棒

### R06 坐标轴和端点刻度

设置 Y 范围 `0.45–0.70`、主刻度间隔 `0.05`、副刻度固定间隔；输入框先全选删除再输入。

预期：输入过程中不被实时刷新打断；端点 `0.70` 出现；负数使用数学负号；自动范围恢复后包含全部数据和误差棒。

### R07 标签与科学文本

编辑长标题、X/Y label、图例条目和标注，验证多行、自动闭合括号、`\*`、
`R_x^y`、`$R_x^y$`、`$v$_sk`、Greek、上下标及 `≤/≥`。

预期：同一输入规则用于所有入口；`R_x^y` 全部为正体，`$R_x^y$` 的变量均按数学斜体处理，
`$v$_sk` 的外部描述下标为正体；普通 Greek 为正体，数学区内的 Greek 为斜体；
预览、保存重开及导出一致；帮助文字清晰可读。

### R08 曲线样式与统一操作

修改颜色、七种线型、实心/空心点形、点尺寸和“每隔点数”；分别勾选尺寸、间隔和填充方式应用于全部曲线。

预期：实时更新；应用全部真正作用于每条曲线，但保留各自点形；颜色名称不含内部前缀；
选中曲线与对应图例条目同时获得清楚且不模糊的视觉反馈。

### R09 手动录入、重复测量与误差棒

分别粘贴逗号、Tab、空格和换行分隔的数据；建立多 Y、多 X；添加重复测量并验证 SD 与 SEM。

预期：X、Y 各自有明确输入区域；重复测量自动计算均值与标准差/标准误；用一组可手算数据核对 SEM 数值；
X/Y error bar 均计入自动范围；误差棒颜色更新到图例，图例误差棒高度随 marker 合理变化。

## 5. 第三阶段：图例、标注与窗口交互

### R10 图例编辑、布局与跨区域拖动

双击图例，修改富文本条目、顺序、行列；拖到图内、图上、图右，再从图外拖回图内；拉伸对象框。

预期：拖动连续、无需快速甩动；松手后才扩展画布外区；85 × 65 mm 主图不变形；
对象框紧贴可见内容；拉伸能自然调整行列；位置坐标在图内外使用统一基准且准确显示。

### R11 标注、换行与连接线

添加多行文字和箭头/连接线；拖动文字、整体和端点；清空文字后关闭编辑器。

预期：默认连接线为黑色 0.9 pt；选框贴合内容；端点可独立拖动；清空并关闭表示删除且可撤销。

### R12 多窗口、主画布与三种屏幕状态

同时打开 axes、曲线、标签、图例、标注、录入数据和出版检查窗口；点击画布并切换普通、Zoom、原生全屏。

预期：小窗均可独立移动和关闭；点击主图不会自动关闭；进入/退出最大化和全屏后窗口可找回；
出版检查不挤压画布且只显示错误/警告，无问题时仅显示通过结论。

### R13 左栏尺寸与文件卡片

在普通和 Zoom 状态拖动左栏到最窄、默认和最宽；测试长文件名与多文件滚动。

预期：宽度松手后不会弹回；默认紧凑；达到最窄时底部自然出现横向滚动条；文件卡片等宽；
删除叉号位于左上且彼此对齐、可点击，文件名不会无限撑宽侧栏。

## 6. 第四阶段：保存、重开与导出

### R14 组合项目保存重开

保存一个包含四个文件、修改后的 XY、固定 ticks、富文本标签、多行图例、图外图例、标注、误差棒的项目，退出并重开。

预期：数据绑定、样式、位置、行列、轴范围和窗口无关文档状态全部恢复；没有旧格式界面回退。

### R15 PDF、PNG、SVG

从 R14 项目分别导出 PDF、透明 PNG 和 SVG。

预期：三种文件均生成且可打开；只包含完整内容所需的紧凑边界；图外图例不造成大片空白；
主图尺寸和长宽比正确；数学字体、`≤/≥`、数学负号、误差棒、图例和连接线与预览一致；无选中框。

### R16 Spotlight 与安装身份

退出后再次从 Spotlight 搜索。

预期：只有一个应用结果；图标、名称、版本和构建号均为当前安装；不会出现旧应用副本或不能打开提示。

## 7. 补充自动回归

真实操作完成后再运行：

```text

cargo clippy --locked --all-targets --all-features -- -D warnings
```

自动回归失败必须与人工结果一起报告，但不能把自动通过写成 R01–R16 的人工 PASS。

## 8. 最终报告格式

- 环境：应用路径、版本、构建号、macOS 和屏幕状态。
- 汇总：PASS / FAIL / BLOCKED / NOT RUN 数量。
- 按 R01–R16 逐项列出结果与关键证据。
- 单列 P0/P1 阻断项、P2 优化项、未能验证的 Windows 最大化/全屏事项。
- 最终结论只能是：`通过`、`有条件通过` 或 `不通过`，并说明下一步。
