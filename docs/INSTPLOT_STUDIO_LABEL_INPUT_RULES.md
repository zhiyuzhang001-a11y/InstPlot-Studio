# InstPlot Studio 标签输入规则

这套输入是有意缩小的科研标签语法，不是完整 TeX。解析结果是 `LabelNode` 语义树，屏幕预览与 PDF/PNG 导出共用它。

## 正体与斜体

- `$...$` 外一律默认正体，包括拉丁字母、希腊字母、数字以及上下标内容：`R_x^y` 中 `R`、`x`、`y` 都是正体。
- 一对 `$...$` 内按数学变量处理：`$R_x^y$` 中 `R`、`x`、`y` 都是斜体。
- 希腊字母遵守同一规则：`α` 或 `\alpha` 是正体；`$α$` 或 `$\alpha$` 是斜体变量。
- 数学区内需要正体时使用 `\mathrm{...}`；数学区外需要显式斜体时使用 `\mathit{...}` 或“斜体”按钮。
- 普通文字、数字和单位直接输入：`300 K`、`Diameter (nm)`。
- 比较符号直接输入 `<=`、`>=`、`!=`，或粘贴 `≤`、`≥`、`≠`；不需要 `$`。
- `*` 是语法字符；要显示字面星号应输入 `\*`。

规范化示例：输入 `$R_x^y$ <= 300 K`，编辑器可规范化为 `$R_{x}^{y}$ ≤ 300 K`。只有变量片段位于 `$...$` 内，`≤`、`300` 和 `K` 不会被多余的 `$` 包围。

## 上下标与单位

- 正体上下标：`R_x^y`、`H_0`、`H_{DL}`。
- 斜体变量上下标：`$R_x^y$`、`$H_z$`。
- 混合样式：`$H_{\mathrm{DL}}$` 中 `H` 为斜体变量，`DL` 为正体描述下标。
- 数值指数：`10^{-3}`、`m^{-2}`，数字和负号保持正体。
- 括号单位：`Current density (A m^{-2})`；数字和单位保持正体。
- 同一基字符同时具有上下标时会叠排在同一侧，而不是前后错开。

## 符号面板

- “希腊字母”面板插入字母本身；在普通区域插入时显示正体。
- 要把插入的希腊字母作为变量，请选中它并使用“斜体”，或把它放入 `$...$`。
- 运算符、关系符号和箭头不因 `$...$` 改为斜体。

## 括号与粘贴

- 键入 ASCII `()`、`[]`、`{}` 时自动补全，并允许直接越过已有右括号。
- 科研图中文字会把常见全角括号规范化为半角；不支持的中文标点不自动生成配对字符。
- 粘贴内容不触发自动补括号，避免改写来自 Word、表格或其他软件的原文。
