# InstPlot Studio 标签输入规则

这套输入是有意缩小的科研标签语法，不是完整 TeX。解析结果是 `LabelNode` 语义树，屏幕预览与 PDF/PNG 导出共用它。

## 何时使用 `$`

- 普通文字、数字和单位直接输入：`300 K`、`Diameter (nm)`。
- 比较符号直接输入 `<=`、`>=`、`!=`，或粘贴 `≤`、`≥`、`≠`；不需要 `$`。
- 单个拉丁数学变量可写 `$v$`；带变量下标写 `$v_{sk}$`，其中 `v`、`s`、`k` 都是斜体变量。
- 描述性正体下标写 `$v$_{sk}` 或 `$v_{\mathrm{sk}}$`，其中 `sk` 为正体。
- 常用希腊变量可直接粘贴或通过“数学符号与希腊变量”插入；语义由符号表确定。
- `*` 是语法字符；要显示字面星号应输入 `\*`。

规范化示例：输入 `$v_{sk}$ <= 300 K`，编辑器可规范化为 `$v_{sk}$ ≤ 300 K`。`≤`、`300` 和 `K` 都不会被多余的 `$` 包围。

## 上下标与单位

- 数学下标：`H_0`、`$v_{sk}$`。
- 描述下标：`H_{DL}` 或 `H_{\mathrm{DL}}`。
- 上标：`10^{-3}`、`m^{-2}`。
- 括号单位：`Current density (A m^{-2})`；数字和单位保持正体。

## 括号与粘贴

- 键入 ASCII `()`、`[]`、`{}` 时自动补全，并允许直接越过已有右括号。
- 科研图中文字会把常见全角括号规范化为半角；不支持的中文标点不自动生成配对字符。
- 粘贴内容不触发自动补括号，避免改写来自 Word、表格或其他软件的原文。
