## 1. 目标与基本原则

InstPlot Studio 在保留当前单 X、单 Y 默认体验的基础上，增加双 Y 或双 X 能力。产品最多同时显示三条独立坐标轴，不开放 X2 与 Y2 同时启用。设计必须同时适用于：

- 一个文件中的多组数据；
- 多个文件中的数据；
- Studio“录入数据”生成的数据；
- 带 X/Y 误差棒的数据；
- 以上来源混合存在的项目。

核心原则如下：

1. 双轴是绘图属性，不是文件格式。
2. 数据源只提供列；曲线负责选择 X/Y/误差列，并绑定到具体坐标轴。
3. 全局开关决定副轴是否存在，曲线属性决定曲线使用哪条轴。
4. 默认仍为单 X、单 Y；未主动开启副轴的用户不应看到额外复杂度。
5. 开关坐标轴不会修改原始文件，也不会改变曲线颜色、点型、线型、图例名称或数据内容。
6. 设计不能依靠叠加第二个 `AxesRecord` 来模拟双轴，以免与未来多子图结构冲突。
7. 一条用户可理解的逻辑曲线必须具有稳定身份；组成点线图的线、点、误差棒和图例共享该身份，不能靠相同列绑定临时猜测归组。
8. 用户主动设置的可见性与副轴关闭造成的休眠是两种状态，切换轴模式不能改写用户的显隐选择。

## 2. 统一坐标轴模型

一个绘图区提供四个可用轴槽位：

- `X1`：底部主 X 轴，始终存在；
- `X2`：顶部副 X 轴，可选；
- `Y1`：左侧主 Y 轴，始终存在；
- `Y2`：右侧副 Y 轴，可选。

全局“坐标轴模式”覆盖三种互斥状态：

- 单 X / 单 Y（默认）；
- 单 X / 双 Y；
- 双 X / 单 Y。

界面上使用一个互斥模式选择：

```text
坐标轴模式
(●) 单 X / 单 Y
( ) 双 Y
( ) 双 X
```

选择“双 Y”时启用右侧 Y2并关闭顶部 X2；选择“双 X”时启用顶部 X2并关闭右侧 Y2。底层可保留两类副轴的休眠设置和曲线绑定，以便在模式之间切换时恢复，但渲染与交互不允许四条独立轴同时出现。

每条曲线增加明确的轴绑定属性：

```text
数据源：文件或录入数据的数据源 ID
X 数据：选定的 X 列
Y 数据：选定的 Y 列
X 误差：可选列
Y 误差：可选列
X 轴：X1 或 X2
Y 轴：Y1 或 Y2
```

这里的分配对象是完整的曲线（X/Y 数据组合），不能只把孤立的 Y 列或整个文件绑定到某条轴。

“完整的曲线”是稳定的逻辑曲线实体，至少包含：

- 稳定的 `series_group_id` 或等价身份；
- 数据源及 X/Y/误差列绑定；
- X/Y 轴绑定；
- 共同组成该曲线的线、点、误差棒 artist；
- 代表该曲线的图例条目和样式关系。

合法轴组合只有：

- `X1/Y1`；
- `X1/Y2`；
- `X2/Y1`。

单条逻辑曲线禁止保存为 `X2/Y2`。项目可以同时保存一组休眠的 X2 曲线和另一组休眠的 Y2 曲线，但产品任一时刻只启用一种副轴。

## 3. 全局开关与衔接规则

### 3.1 先导入数据，再开启副轴

这是预期的常用流程，必须无缝支持：

1. 已有曲线继续使用 `X1/Y1`，图形不能突然改变。
2. 开启 Y2 或 X2 后，只增加可用的副轴和相应编辑入口。
3. 曲线设置开始显示已启用的轴选项。
4. 用户手动把目标曲线分配到副轴。
5. 副轴根据分配给它的曲线独立自动缩放。
6. 图例顺序、颜色、点型、线型和数据关系保持不变。

副轴刚开启但尚无曲线时，不显示没有意义的 `0–1` 刻度。可以只显示轴线/标签入口，或以轻量待设置状态表示尚未绑定数据。

### 3.2 先开启副轴，再导入数据

导入行为仍保持默认和可预测：

1. 新曲线默认绑定 `X1/Y1`。
2. 软件不能因为副轴已经打开就擅自猜测并移动曲线。
3. 用户随后在曲线设置中选择 X1/X2、Y1/Y2。
4. 明确的列名可用于建议，不用于不可撤销的自动分配。

### 3.3 关闭副轴

最终确认的规则是“隐藏并保留”，不迁移到主轴：

- 关闭 Y2 后，所有绑定 Y2 的曲线、误差棒和对应图例条目暂时隐藏；
- 关闭 X2 后，所有绑定 X2 的曲线、误差棒和对应图例条目暂时隐藏；
- 隐藏曲线不参与主轴自动范围计算；
- 数据源、列绑定、样式、图例顺序和副轴设置均保留；
- 左栏或曲线设置应提示“Y2/X2 已关闭，曲线已隐藏”，避免用户误以为数据丢失；
- 再次打开副轴时，曲线、误差棒、图例和轴设置原样恢复；
- 导出只包含当前启用坐标轴上的可见内容。

因此，允许项目内部保留“曲线绑定到当前关闭的副轴”的休眠状态，但渲染、图例和自动范围必须统一排除这些曲线。

休眠不能通过把 artist 的持久 `visible` 改成 `false` 实现。全系统使用同一个有效可见性规则：

```text
effective_visible =
    用户保存的 artist.visible
    &&（对象没有数据轴绑定
       || 对象依赖的 X/Y 轴当前均启用）
```

预览、命中测试、选择高亮、自动范围、图例、出版规范检查和所有导出后端都必须使用 `effective_visible`。重新开启副轴时，仅恢复因轴休眠的内容；用户原本主动隐藏的内容仍保持隐藏。普通画布文字等无数据轴绑定对象不因副轴切换而隐藏；图例容器本身保持可见，只过滤依赖休眠曲线的条目。

### 3.4 对称刻度恢复

顶部和右侧边缘既可以显示主轴的对称刻度，也可以成为独立副轴：

- 单轴模式：顶部刻度镜像 X1、右侧刻度镜像 Y1，默认不重复显示顶部/右侧刻度标签；
- 双 Y 模式：右侧改为独立 Y2，顶部仍镜像 X1；
- 双 X 模式：顶部改为独立 X2，右侧仍镜像 Y1；
- 从双轴模式返回单轴时，原副轴一侧立即恢复主轴对称刻度，不得残留副轴的数值、标签或格式。

## 4. 导入文件的数据组织方式

软件应支持下列常见格式，不能假定双 Y 数据一定具有固定列数。

### 4.1 多条曲线共享 X

```text
X, Y1, Y2
```

形成两条曲线：

- 曲线 A：`X + Y1`；
- 曲线 B：`X + Y2`。

之后由用户决定曲线 B 是否使用右侧 Y2。

### 4.2 每条曲线具有独立 X

```text
X1, Y1, X2, Y2
```

形成两组独立 X/Y 配对。两组行数或采样位置可以不同。

### 4.3 多个文件

每个文件照常选择自己的 X/Y 列并生成曲线。例如：

- 文件 A 的曲线使用 `X1/Y1`；
- 文件 B 的曲线使用 `X1/Y2`。

不能把“一个文件”等同于“一条轴”，因为一个文件可能包含多条曲线，而且同一文件中的不同曲线也可能属于不同坐标轴。

### 4.4 误差数据与重复测量

应继续支持：

```text
X, Y1, Y1_err, Y2, Y2_err
X, X_err, Y, Y_err
X, Y1_repeat1, Y1_repeat2, Y1_repeat3, ...
```

误差列或重复测量结果跟随所属曲线以及该曲线的轴绑定。

### 4.5 自动识别边界

- 可根据明确列名建议 `X/Y` 配对，例如 `X1/Y1`、`X2/Y2`；
- 对 `X, Y1, Y2` 可以建议共享 X 的两条曲线；
- 无法可靠判断时保持普通导入，由用户选择；
- 自动建议必须可以修改；
- 不追求对任意科研文件进行完全自动且不可见的猜测。

同一文件需要支持增加多条曲线，而不只是保留第一组 X/Y。

## 5. 录入数据与导入文件统一

现有“录入数据”在点击“绘图”或“应用修改”后，会成为当前项目中的独立数据源，并在左栏出现数据卡片。再次打开录入窗口时，可以从保存的录入配方恢复 X、Y、重复测量和误差设置。

双轴功能不为录入数据另建一套逻辑。录入数据和文件导入应统一走：

```text
数据源
  -> 选择 X/Y/误差列
  -> 生成曲线
  -> 曲线绑定 X1/X2、Y1/Y2
```

规则如下：

- 录入数据卡片与导入文件卡片都可生成曲线并使用同一套轴绑定属性；
- 同一项目中同时存在导入文件和录入数据时，轴绑定、颜色、点型、图例、保存和删除行为不能混淆；
- 关闭副轴只隐藏相应曲线，不删除录入数据或文件数据；
- 重新打开副轴后，两类来源的曲线都按原绑定恢复。

### 5.1 数据保存边界

- 导入文件始终保持只读，不因轴设置或项目保存而改写原文件；
- 项目应保存数据源身份、列绑定、曲线样式和轴绑定等绘图信息；
- 是否继续使用现有嵌入/缓存策略，不由双轴功能改变；
- 录入数据没有天然的外部原文件，继续采用当前方案：在项目中保留可编辑配方和嵌入数据；
- 用户正式保存项目时，可将录入数据生成 CSV、TSV、TXT、DAT 或 XLSX 独立文件；
- “应用修改”会立即更新当前内存项目，但不等于已经自动写入硬盘；项目仍遵循现有未保存提示和显式保存流程。

## 6. 轴标签与数据列的职责

轴本身不直接选择文件列。原因是同一轴可能同时承载多个文件、多个 Y 列以及多条曲线。

轴属性包括：

- 轴 ID 和位置；
- 是否启用；
- 轴标签及单位；
- 自动/手动范围；
- 主刻度和副刻度；
- 字体、颜色及其他轴外观。

曲线属性包括：

- 数据源；
- X/Y/误差列；
- X 轴和 Y 轴绑定；
- 线条、点、颜色、图例等样式。

可以提供不具破坏性的标签建议：

1. 第一条曲线分配到尚未使用的 Y2/X2 时，根据列名和单位建议轴标签；
2. 用户可接受或修改建议；
3. 副轴已经有标签后，新增曲线不能自动覆盖它；
4. 多条曲线单位不一致时应警告，而不是擅自改标签或换算数据。

单位警告只有在软件能从结构化信息或明确格式中可靠获得单位时才启用；不能仅根据模糊列名猜测。无法可靠识别时保留人工标签编辑，本阶段不做自动换算。

## 7. 自动范围、刻度与误差棒

每条启用的轴必须独立计算范围：

- X1 只统计绑定 X1 且当前可见的曲线；
- X2 只统计绑定 X2 且当前可见的曲线；
- Y1 只统计绑定 Y1 且当前可见的曲线；
- Y2 只统计绑定 Y2 且当前可见的曲线。

自动范围必须包含：

- 数据点；
- X 误差棒完整范围；
- Y 误差棒完整范围；
- 数据参考线，并保持当前既有的范围行为。

箭头的数据连接目标和普通数据标注默认不扩展自动范围，除非以后增加明确的“参与自动范围”属性；否则远处标注可能意外拉大坐标范围。画布坐标文字永不参与数据范围。

关闭副轴后，其休眠曲线不能污染主轴范围。重新打开后，副轴应恢复或重新计算正确范围，确保数据和误差棒完整可见。

刻度、格式化、科学计数法和数学负号都应对所有主轴与副轴使用同一套规范。网格线默认仅由主轴控制，避免双轴网格相互冲突；副轴网格若将来开放，应为显式选项。

轴线和刻度默认继续使用统一的黑色/中性色，不强制跟随某条曲线的颜色。若以后提供“轴颜色跟随曲线”，只能作为用户主动选择的显示选项，因为同一轴可能承载多条不同颜色的曲线。

使用数据坐标的参考线、箭头或标注必须记录所属的 X/Y 轴组合；使用画布坐标的普通文字不需要绑定数据轴。副轴关闭时，依赖该副轴数据坐标的对象应与相应曲线一起隐藏，避免出现在错误位置。

## 8. 布局、交互与导出

### 8.1 布局

- X2 位于绘图区顶部，Y2 位于绘图区右侧；
- 四侧边缘必须具有唯一所有者：单轴时 X1/Y1 拥有远端镜像刻度；双 Y 时 Y2 接管右侧且 Y1 远端刻度停止绘制；双 X 时 X2 接管顶部且 X1 远端刻度停止绘制；关闭副轴后所有权归还主轴；
- 统一 `AxisSlot` 或等价模型负责边缘身份和所有权，禁止主轴 far ticks 与副轴 ticks 同时竞争同一边缘；
- 正式布局输入包含 X1/Y1 及当前模式下的可选 X2 或 Y2；每条逻辑曲线、参考线和数据坐标连接点携带轴组合；
- 所有数据到画布的映射函数必须接收轴组合，不能继续固定读取全局 `chart.x/chart.y`；
- 布局结果保存四侧当前轴的几何、标签边界和命中区域，供预览和导出共同使用；
- `width_mm/height_mm` 继续表示现有单轴基础画布尺寸，不改变旧项目语义；它不是重新定义后的纯数据绘图区尺寸；
- 启用副轴或图外图例时，只向相应方向扩展外围画布，使原有单轴数据区域几何保持不变；最终 resolved canvas 可以大于基础画布；
- 顶部或右侧所需空间通过扩展外围画布解决，不能任意压缩某一个未来子图；
- 额外边距应紧凑，只足以完整容纳刻度标签、轴标签和其他可见内容；
- 图内图例与图外图例应继续基于统一坐标和内容边界工作。

### 8.2 交互

- 双击底部、顶部、左侧或右侧轴，打开对应轴的编辑窗口；
- 曲线设置只列出当前模式已经启用的轴；
- 当前绑定到关闭副轴的曲线需要清晰显示“已隐藏”，并允许用户在不开轴或开轴后重新分配；
- 切换轴绑定后立即更新预览、自动范围、选中高亮和图例对应关系；
- 所有新窗口遵循现有统一窗口规则：再次触发时置顶，而不是重复创建或自动关闭。
- 左下角悬停坐标显示当前模式的全部有效坐标：单轴显示 `X1/Y1`，双 Y 显示 `X1/Y1/Y2`，双 X 显示 `X1/X2/Y1`；不能固定只按 X1/Y1反算。

### 8.3 图例

- 图例仍描述曲线，不描述坐标轴；
- 无论单轴、双 Y 还是双 X，图例默认仍放在图内，不因开启副轴而自动迁移；
- 用户需要图外图例时，双 Y 模式优先提供图上方位置，双 X 模式优先提供图右侧位置；这是推荐位置而非强制位置；
- 图外图例通过增加紧凑的外围画布容纳，主绘图区尺寸和长宽比保持不变；
- 图上方图例应支持自动选择紧凑的行列数，图右侧图例应优先使用紧凑的纵向或多列排列；
- 用户仍可选择其他已有图例位置或手动拖动，模式切换不得覆盖用户明确设置的位置；
- 曲线切换轴时图例文字、顺序和样式保持不变；
- 绑定到关闭副轴而隐藏的曲线，其图例条目同时隐藏；
- 重新启用副轴后，图例条目在原顺序恢复。

### 8.4 关键边界

- 无数据副轴不能显示虚假的 `0–1` 刻度；删除副轴最后一条曲线后应进入明确的无数据状态；
- 空列、单点、`NaN`、无穷值及误差棒不能破坏自动范围；
- 从双 Y 切换到双 X 时，Y2 曲线进入休眠并隐藏，X2 曲线按已保存绑定恢复；反向切换同理；
- 长刻度标签、科学计数法、长轴标签及图例要重点检查左上、右上和右下角的碰撞与裁切；
- 重新载入列结构发生变化的源文件时，不能把曲线静默绑定到错误列；
- 保存、重新打开、撤销与重做必须完整保持模式、休眠绑定、轴设置和图例位置；
- 窗口化、最大化、全屏以及 PDF、SVG、PNG 导出必须使用相同的内容边界；
- 输出边界只需紧凑包含全部可见内容，不得裁切，也不得产生无意义的大面积空白。
- 出版规范检查必须排除休眠曲线，并使用 resolved layout 的最终画布尺寸、物理尺寸和像素尺寸，不能只读取项目中的基础 `width_mm/height_mm`；
- 基础 `width_mm/height_mm` 保持既有“单轴基础 figure canvas”语义；副轴或图外图例增加的外围区域计入最终导出尺寸并在出版检查中准确报告。

### 8.5 导出

PDF、SVG 和光栅导出必须与画布一致：

- 导出当前启用的坐标轴；
- 导出当前可见的曲线和图例条目；
- 四侧边缘当前承担的主轴镜像刻度或独立副轴、标签、误差棒、文字和线宽均保持出版规范；
- 输出边界完整包含内容，同时避免无意义的大面积空白；
- 导出不能改变项目状态或源数据。

## 9. 项目格式与兼容性

预计需要项目 schema 从当前版本升级，并提供明确迁移：

- 旧项目只有 X1/Y1；
- 所有旧曲线迁移后默认绑定 X1/Y1；
- X2/Y2 默认为关闭，且不能同时启用；
- 同一逻辑曲线的线、点和误差棒迁移为共同的稳定身份；
- 参考线及数据坐标箭头连接点迁移为 X1/Y1组合；普通画布文字不增加轴绑定；
- 旧项目打开后的外观和导出结果应尽可能保持一致；
- 新项目保存轴启用状态、四条轴的设置以及每条曲线的轴绑定；
- 保存并重新打开后，关闭副轴上的休眠曲线及其设置必须完整恢复。

底层模型应能分别保存 X2 和 Y2 的设置与休眠绑定，即使产品第一阶段只开放双 Y。这样双 X 不需要再次重构核心结构，但产品校验必须禁止 X2/Y2 同时启用。

迁移测试必须覆盖当前支持的全部历史 schema 0–7及新增版本，不能只使用一个笼统旧项目样本。新增字段需要可靠默认值或显式 JSON 规范化，保证旧版本逐级迁移后与单轴基线一致。

旧项目没有逻辑曲线 ID，迁移必须采用保守、确定且不破坏视觉的归组策略：

1. 保留全部原 artist 的 ID、顺序、属性、可见性和图例数量，迁移不得删除或合并 artist；
2. 先按旧图例条目建立锚点组：不同图例条目引用的代表 artist 即使数据绑定相同，也保持为不同逻辑组；
3. 对每个尚未归组的互补 line、scatter 或 error-bar，如果它只能唯一匹配一个具有完全相同 `DataBinding` 的锚点组，并符合现有点线/误差棒创建关系，则加入该锚点组；
4. 对完全没有图例锚点的剩余 artist，仅在每种互补类型候选唯一且归属无歧义时组成共同逻辑组；
5. 多个锚点、多个同类型候选或重复绑定导致歧义时，不强行合并；各 artist 保留独立逻辑组并给出非破坏性迁移警告；
6. 无法可靠归组时保持原视觉、样式和图例数量，不得静默丢失或重排内容；
7. 逻辑组 ID 基于锚点 artist ID 或稳定文档顺序确定生成，禁止使用随机值；相同旧项目每次打开必须得到相同结果，并在首次保存新 schema 后稳定持久化。

## 10. 建议实施阶段

### 阶段 A：模型与兼容

1. 为坐标轴建立稳定 ID/槽位模型；
2. 为逻辑曲线建立稳定身份，将线、点、误差棒和图例归组；
3. 为逻辑曲线增加 `x_axis_id`、`y_axis_id`并限制合法组合；
4. 为参考线和数据坐标连接点增加轴组合；
5. 增加轴启用状态、边缘槽位和项目迁移；
6. 保证旧项目全部落到 X1/Y1，并覆盖 schema 0–7。

### 阶段 B：双 Y 最小完整闭环

1. 增加全局 Y2 开关；
2. 增加曲线 Y1/Y2 选择；
3. 完成有效可见性和 Y2 独立映射、刻度、标签及自动范围；
4. 实现关闭休眠、重新开启恢复且不改变用户显隐；
5. 完成边缘所有权、图例、出版检查和导出一致性。

双 Y 比双 X 更常见，适合作为第一批可见功能。

### 阶段 C：双 X

1. 开放 X2 开关和曲线 X1/X2 选择；
2. 完成顶部轴布局与交互；
3. 验证单轴、双 Y、双 X 三种互斥模式及双 Y/双 X直接切换。

### 阶段 D：导入与录入增强

1. 同一文件创建多条曲线；
2. 对明确列名提供 X/Y 配对建议；
3. 验证多文件、录入数据及混合来源；
4. 验证 X/Y 误差棒和重复测量。

### 阶段 E：完整 QA

覆盖窗口化、最大化和全屏状态，并检查预览、保存、重新打开、PDF、SVG 和光栅导出。

## 11. 验收场景

至少逐项验证以下场景：

1. 旧单轴项目打开后无视觉回归。
2. 先导入文件，再开启 Y2，已有曲线不移动。
3. 先开启 Y2，再导入文件，新曲线仍默认使用 Y1。
4. `X,Y1,Y2` 创建共享 X 的两条曲线，并将其中一条放到 Y2。
5. `X1,Y1,X2,Y2` 创建两条独立采样曲线。
6. 两个文件的曲线分别绑定 Y1、Y2。
7. 同一个文件的不同曲线分别绑定 Y1、Y2。
8. 录入数据与导入文件同时存在并分别绑定主、副轴。
9. Y2 曲线带 Y 误差棒，自动范围完整包含误差棒。
10. X2 曲线带 X 误差棒，自动范围完整包含误差棒。
11. 关闭 Y2 后曲线和图例隐藏，Y1 范围不受影响。
12. 再次打开 Y2 后曲线、样式、误差棒、图例顺序和轴设置恢复。
13. 保存副轴关闭的项目，重开后休眠绑定仍正确。
14. 删除数据源时，只删除关联曲线，不破坏另一条轴上的无关数据。
15. 清除全部数据后当前坐标轴模式回到合理空状态，再导入仍能正常自动缩放。
16. 改变配色方案后，线条、点和误差棒仍保持同系列一致。
17. PDF、SVG、PNG 导出与画布一致，无裁切和过大空白。
18. 窗口、最大化、全屏三种状态下，轴编辑窗口和曲线设置均可正常操作。
19. 点线图的线、点、误差棒和图例始终作为同一逻辑曲线切换坐标轴。
20. 用户主动隐藏的副轴曲线在关闭并重开副轴后仍保持隐藏。
21. 项目校验和 UI 均拒绝单曲线 `X2/Y2` 组合。
22. schema 0–7项目迁移后保持单轴外观、数据及导出语义。
23. 双轴与图外图例的出版检查报告最终 resolved 画布尺寸。
24. 左下角坐标信息按当前模式显示两项或三项有效坐标。

## 12. 本阶段不包含的范围

- 多子图和每个子图各自的双轴；
- inset axes；
- 自动单位换算；
- 对任意文件列含义进行不可见的完全自动推断；
- 三条或更多同方向 Y 轴；
- 双轴之间的数学变换/联动轴（例如摄氏度与华氏度自动换算）。

这些能力不能通过当前双轴实现方式被永久阻塞，但不属于本次功能范围。

## 13. 已确定与待实现

已经确定的产品决策：

- 使用单轴、双 Y、双 X 三种全局互斥模式，最多同时显示三条独立坐标轴；
- 曲线持有数据列选择和轴绑定；
- 逻辑曲线具有稳定身份，线、点、误差棒和图例共享轴绑定；
- 单曲线只允许 X1/Y1、X1/Y2、X2/Y1，不允许 X2/Y2；
- 默认单 X/单 Y；
- 开启副轴不自动移动已有曲线；
- 关闭副轴隐藏并保留对应曲线，不迁移到主轴；
- 重新打开副轴完整恢复；
- 单轴模式的顶部和右侧恢复为主轴对称刻度；
- 用户可见性与副轴休眠分离，全系统使用统一有效可见性；
- 四侧边缘具有唯一所有者，主轴镜像刻度与副轴刻度不重复绘制；
- 图例始终默认位于图内；双 Y 可迁至图上方，双 X 可迁至图右侧，但不自动强制迁移；
- 导入文件和录入数据共用同一套曲线/轴逻辑；
- 轴标签独立于数据列，但可以根据第一条曲线提供建议；
- 文件源数据不因绘图而被修改；
- 第一阶段优先交付双 Y，底层同时为双 X 建模。

当前进度：项目模型、schema 8、历史迁移、逻辑曲线身份、轴绑定和边缘唯一所有权已完成并通过 Phase 1 门禁。尚未完成的工作是 document 层模式切换与独立自动范围、布局与渲染、界面实现以及最终完整 QA；后续实现继续以本文作为行为和验收基准。
