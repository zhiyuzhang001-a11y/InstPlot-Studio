## 最终决策摘要（本轮唯一权威方案）

- 一个“手动数据组”就是一条完整 XY 曲线；X、Y、重复测量、统计方式和图形类型在同一张卡片内；
- 手动数据绘图后进入与文件导入完全相同的数据源、系列、样式、图例、自动范围和撤销管线，
  仅额外保留可恢复编辑的 `manual` 来源与录入配方；
- 每个已保存的手动数据组在左栏独立显示，不能与导入文件或其他手动组错误合并；左栏不提供
  双击编辑，录入窗口内通过明确的“编辑 / 应用 / 取消”修改旧数据；
- 导入文件与手动数据按创建顺序共用连续的颜色和 marker 序列；同一曲线的 line、marker 与
  error bar 默认同色，删除其他来源不能造成错误重绑定或意外重着色；
- 录入窗口只负责录入和绘图，不选择保存格式。保存项目或另存为时再为手动数据选择
  CSV/TSV/TXT/DAT/XLSX 与目录；原始导入文件永不被覆盖；
- 项目始终嵌入完整手动原始数据和配方；外部手动数据文件用于交换与长期记录，删除项目卡片
  默认不删除磁盘文件；
- 本轮同时完成误差棒端点 autoscale、固定间隔端点刻度、默认线宽和混合来源回归；双 Y 轴与
  inset axes 明确留到后续阶段。

## 1. 目标

在不把 Studio 变成电子表格或增加主界面负担的前提下，补齐两类常见科研绘图需求：

1. 用户可以明确控制 marker 每隔多少个数据点显示一次；
2. line、line + marker、scatter 和 error bar 在图例中使用正确且不同的示意；
3. 用户可以直接录入或粘贴少量实验数据，包括同一 X 下的多次重复测量，并立即生成普通
   曲线、散点或 error bar。

## 2. Marker 数量与大小

- marker 默认在全部有效数据点上显示，即间隔为 1；
- 对象窗口提供“每隔 N 个点显示”，N 为正整数；N=1 表示全部显示，N=2 表示每两个点显示
  一个 marker；
- 抽样规则必须确定，首个数据点始终显示；是否强制显示末点需固定为同一规则，不能随预览尺寸变化；
- 少量散点使用稍大的 marker，保证辨识度；
- 点数很多的曲线可以使用较小 marker，但默认仍全部显示，由用户主动改变间隔；
- 线仍使用全部有效数据点，marker 仅做确定性抽样显示，不能改变数据或拟合结果；
- marker 大小可使用“小 / 标准 / 大”，line 与 scatter 可以有不同的默认大小；
- 空心/实心可应用到全部散点或点线系列，但只能改变填充状态，不能覆盖每条曲线自己的
  marker 形状、颜色、大小和显示间隔；
- 保存重开、PDF/PNG 和画布预览必须使用同一 marker 尺寸与抽样规则。

## 3. 图例必须反映实际图形

- line only：图例只画线段；
- line + marker：图例画线段，并在中央画实际 marker；
- scatter：图例只画 marker，不能带一条不存在的连接线；
- error bar：图例至少表达该系列的 marker/line 风格，并显示简洁的误差棒语义；
- 空心/实心、颜色、线型和 marker 形状必须与主图一致；
- marker 显示间隔只影响主图密度，不应让图例中的 marker 消失。

### 3.1 七种线型补充（已完成）

- 线型与七种颜色、七种 marker 使用一致的循环序号；
- 在现有实线、虚线、点线、点划线之外，增加长虚线、长短划线和双点划线；
- 三种新增线型必须在 85 × 65 mm 画布、细线、PDF 和常用缩放比例下仍能与现有线型明显
  区分；不能只靠非常接近的疏密变化；
- 图中曲线、图例、画布预览和 PDF/PNG 导出必须使用同一 dash pattern；
- 第一版不开放任意 dash 数组编辑，避免难以辨认或不适合出版的小间隔组合。

### 3.2 科研标注补充（已完成）

- 本轮不增加 inset axes，也不以普通方框伪装独立坐标区；多 axes/插图留到后续阶段单独设计。
- 普通文字标注支持在输入框中直接按 Enter 换行；多行排版、选择框、拖动、PDF/PNG 导出和保存
  重开必须一致。
- 增加统一的“连接线标注”对象，通过端点箭头模式覆盖普通连接线、末端箭头、起点箭头和双向箭头，
  不分别制造多套对象和窗口。
- 一段文字允许连接一支或多支箭头，适合一个物理量标签同时指向多个特征点。
- 文字位置和每个端点均可独立拖动；箭头端点可绑定数据坐标，使坐标范围改变后仍指向原数据点，
  文字位置可保留为画布坐标以方便排版。
- 连接线复用产品的颜色、线宽和七种线型；箭头大小提供受限范围，避免过大、过小或影响出版观感。
- 单击选中时显示不参与导出的端点控制柄；双击打开编辑窗口；支持复制、删除和前移/后移层级。
- 矩形、椭圆、高亮区域、花括号等通用矢量形状暂不进入第一版，避免把 Studio 扩张为通用绘图器。
- 验收覆盖单行/多行文字、无箭头/单箭头/双箭头、一段文字连接多箭头、轴范围改变后的数据锚定、
  保存重开、PDF/PNG，以及普通、最大化和全屏窗口。

## 4. 顶部“录入数据”入口

- 主界面顶部栏新增四字入口“录入数据”，不放入“文件”菜单；
- 窗口标题使用更完整的“录入或粘贴数据”；
- 同一窗口同时支持逐行键入和从 Excel、Origin、Word、文本文件等来源粘贴；
- 提交后形成正式 data source；未命名数据组统一使用 `Data N`（例如 `Data 1`），并进入现有左侧
  文件/数据区域。自动名称不得使用中文，以免默认图例进入不受支持的 CJK 出版文字路径；
- 手动数据与导入文件遵循相同的颜色、图例、删除、撤销、项目保存和导出规则。
- 完成绘图后，手动录入的数据像导入文件一样以独立数据源出现在左栏；清除全部数据后可重新
  录入，不依赖示例图或旧数据状态。

## 5. 粘贴格式兼容

优先复用现有文件导入中已经验证的分隔符检测与数值解析能力，不能再维护一套行为不同的粘贴
解析器。录入窗口只增加适合剪贴板的预览和列角色，不复制核心解析规则：

- 制表符：优先兼容 Excel、Origin 和表格软件复制内容；
- 逗号：兼容 CSV，并正确处理带引号字段；
- 分号：兼容部分地区和仪器软件的导出格式；
- 连续空格：兼容常见纯文本数据；
- 换行划分记录，空行自动忽略；
- 粘贴内容不识别表头；第一行始终作为数据处理；
- 出现文字表头或其他非数值内容时明确指出具体行列，让用户删除后重试，不进行猜测；
- 空单元格保留为缺失值，绝不能静默转换为 0；
- 小数逗号只在制表符或分号作为列分隔符时自动识别，避免与 CSV 逗号歧义；
- 分隔方式或小数格式存在歧义时必须显示预览并让用户确认，不能静默选错。

## 6. 录入模式

本轮只采用“完整 XY 数据组卡片”模型，以下 6.1–6.7 为权威定义。旧的“分别增加 X/Y、再让
Y 选择 X”模型全部移除，不再保留两个并行入口或兼容层。用户确认“绘图”或“应用修改”后才
原子更新正式数据源、曲线和误差棒；取消或校验失败不得改变项目。

## 6.1 XY 数据组录入最终方案（2026-09-26）

- 录入窗口使用与对象编辑器相同的可移动、可缩放窗口规则；普通、最大化和全屏状态均不能
  丢失窗口，点击主画布也不能自动关闭；
- 一张“数据组卡片”代表一条独立曲线，X 与 Y 必须在同一卡片内并排呈现；不再分别维护
  “全部 X”和“全部 Y”，也不再要求用户理解额外的 X/Y 配对关系；
- 每张卡片包含数据组名称（初始图例文字）、一组 X、一组 Y、X/Y 各自的重复测量、SD/SEM、
  图形类型以及稳定的数据源身份；
- “＋新增数据组”创建另一张完整的 XY 卡片；不再提供“新增 X 组”和“新增 Y 组”。卡片内部
  的“＋重复测量”只增加相应 X 或 Y 的统计重复，用于计算 X/Y error bar；
- 每个输入框只负责一列数值，接受换行、Tab、空格、逗号和分号；不识别表头。非法数值、
  重复测量长度不一致或一对 XY 长度不一致时必须指出具体数据组、X/Y 与测量编号；
- 新数据组直接进入编辑状态；已保存数据组继续显示在窗口中但默认只读，必须点击卡片上的
  “编辑”才能修改。同一时间只允许编辑一个旧数据组，并提供“保存修改”和“取消修改”；
- 不通过双击左侧栏卡片进入编辑。修改旧数据应原位更新同一稳定数据源，保留其颜色、marker、
  线型、图例顺序和用户样式，不能重复创建另一条曲线；
- 原始重复测量、均值、SD/SEM 和误差都保存在正式数据源中，不能只留下统计结果或图形。

## 6.2 录入数据与左侧栏同步

- 每个已保存的手动 XY 数据组在左侧栏生成一张独立卡片，不与 CSV/TXT/XLSX 导入文件合并，
  不同手动数据组之间也不能因名称或路径相同而合并；
- 左栏卡片只紧凑显示数据组名称和 X/Y 名称。单击只负责选择对应曲线；左上角叉号负责删除；
  不显示原始数值、复杂操作或双击编辑入口；
- 录入窗口中的“删除数据组”和左栏叉号必须调用同一条删除命令。从任一入口删除后，另一处
  立即消失，同时移除数据源、line、marker、X/Y error bar 和对应图例条目；
- 删除支持撤销，撤销后完整恢复原始输入、统计设置、曲线样式、图例和录入窗口卡片；有未保存
  修改时删除需要确认，普通已保存数据组直接删除并依靠撤销恢复；
- 正在编辑的数据组若从左栏删除，录入窗口必须退出该编辑状态，不能留下失效表单；
- “清除全部”一次删除所有导入文件和手动数据组并可整体撤销。删除最后一个数据源后恢复空白
  默认画布，再次录入或导入仍须正常自动范围。

## 6.3 同批交互修订（2026-09-25）

- 坐标范围、主刻度间隔和副刻度间隔改为文本缓冲编辑：编辑时允许暂时为空，按 Enter 或失焦
  后才校验并应用，Esc 恢复；不能因实时更新导致用户无法删掉旧值；
- 数据文件区标题行的“清除全部”叉号移到左侧，并与每张文件卡片的删除叉号纵向对齐；
- marker 尺寸和显示间隔各自在右侧提供独立的“应用于全部曲线”复选框。默认只改当前曲线，
  两个属性不能互相覆盖，也不再使用额外的大按钮。

## 6.4 清除全部后的空白默认画布（已完成）

- “清除全部数据”不能保留已经删除数据的 XY label、坐标范围、主刻度间隔或副刻度间隔；这些
  数据相关状态必须一起重置，避免空画布继续表达旧实验含义。
- 清除后显示空白默认坐标框，而不是重新载入七条示例曲线：XY label 清空，X/Y 范围恢复
  `0–1`，主刻度和副刻度恢复自动。
- 保留与数据无关的产品规范，包括 85 × 65 mm 画布、四条 spine、四边向内刻度、字体和默认
  线宽；清除数据不应破坏出版样式。
- 再次导入或录入数据时，根据新选择的 X/Y 列重新生成标签、自动范围和刻度，不能继承被清除
  数据的状态。
- 删除单个文件时不能无条件重置全部坐标轴；应根据剩余可见系列重新自动缩放，并保留仍然有效
  的标签。清除全部必须作为一次可撤销操作，撤销后完整恢复数据和原坐标状态。

## 6.5 独立数据文件与项目保存

- 手动数据采用双重保存：用户选择的独立数据文件用于交换和长期实验记录；`.instplot` 项目同时
  嵌入完整数据与录入结构，保证外部文件移动、离线或缺失时仍能重开、编辑和导出图形；
- 录入数据窗口只负责输入、统计、编辑和绘图，不显示文件格式、保存路径或文件选择器；新数据组
  使用“绘图”，旧数据组使用“应用修改”，两者都先原子写入当前项目内存、更新画布与左栏；
- 用户最后执行“保存项目”或“另存为”时，才在标准保存流程中确定独立数据文件格式与位置。
  第一版支持 CSV、TSV、TXT、DAT 和 XLSX，默认建议 CSV；取消保存时项目保持未保存状态，已经录入的内容
  继续留在当前窗口和画布中，不能被静默丢弃；
- 第一次保存项目时同时确定手动数据文件目录与统一格式；CSV/TSV/TXT/DAT 为每张 XY 卡片生成一个独立
  文件，XLSX 也保持每个数据组独立。选择结果写入项目设置，后续 `Cmd/Ctrl+S` 原子更新项目和
  已关联数据文件，不重复弹出格式选择；“另存为”允许重新确定目录和格式；
- 每张 XY 数据组对应一个独立数据文件。文件必须保存数据组名称、X/Y 名称、全部原始重复测量、
  均值、SD/SEM 类型及误差列等基本信息，不能只输出屏幕上正在绘制的均值；
- CSV 使用逗号分隔，TSV/TXT/DAT 统一使用 Tab 分隔，并使用稳定、可重新识别的列语义；XLSX 使用数据表和元信息表。所有格式都必须能由
  Studio 和 Lite 重新导入，不依赖界面语言或通过中文列名猜测结构；
- 保存后的数据组记录文件路径、格式和指纹。录入窗口中的“应用修改”只更新项目内状态；下一次
  保存项目时再原子更新关联文件。另设“导出数据”用于随时选择其他格式或位置；若文件被外部
  修改，必须提示覆盖、另存或重新载入，不能静默覆盖；
- 删除项目中的数据组默认只解除项目关联并删除图形，不删除磁盘上的实验文件。若以后提供
  “同时删除文件”，必须是单独、明确、可确认且尽量移入废纸篓的操作；
- 保存项目并重开后，左栏与录入窗口恢复全部手动数据卡片。已保存卡片默认只读，点击“编辑”
  后恢复原始输入。只导出 PDF/PNG/SVG 不等于保存数据或项目；
- 旧项目中只有展开后数值列、没有录入配方的手动数据仍须可绘制、导出和删除，但不能伪造原始
  重复测量；界面应明确标记为不可恢复表单的旧数据源。

## 6.6 配色、marker 与自动范围

- 配色单位是独立 XY 数据组，而不是文件或内部数据源。不同卡片按当前色板依次使用不同颜色和
  marker；新增卡片从下一组样式继续，不能每次从蓝色重新开始；
- 同一卡片的 line、marker、error bar 必须同色；切换配色方案后不同 XY 卡片仍保持不同颜色，
  拟合曲线继续跟随其原始数据曲线；
- 新增或修改数据后，自动范围必须包含全部中心点、`X ± X error` 和 `Y ± Y error`，并给误差
  棒端帽保留正常视觉留白；删除卡片后根据剩余可见数据重新计算；
- 用户已经关闭 autoscale 或固定坐标范围时，编辑数据不能擅自覆盖其手动范围。

## 6.7 导入文件与手动数据的统一生命周期

- 手动数据点击“绘图”后必须进入与普通文件导入相同的正式数据源、系列和图例管线；配色、
  marker、线型、图例、autoscale、选择、删除、撤销、项目保存和导出不能维护两套实现；
- 两类数据仍保留明确来源身份：文件导入记录原始文件路径、指纹和嵌入快照；手动数据记录录入
  配方、尚未最终保存时的稳定虚拟身份，以及保存项目后生成的数据文件路径和指纹；
- 左侧栏按实际创建/绘图顺序混合排列导入文件与手动数据卡片，不能先按来源类型重新分组导致
  曲线、颜色、marker 或图例顺序错位；视觉风格统一，但来源类型应能被简洁识别；
- 样式分配以独立 XY 曲线为单位，并跨两类来源使用同一连续序列。例如依次导入文件 A、录入
  数据 B、导入文件 C、录入数据 D 时，应依次取得色板和 marker 的第 1–4 项；同一曲线的
  line、marker、error bar 始终一致；
- 删除其中任一来源不能错误删除、重绑定或重排其他来源。普通删除不自动重绘剩余曲线的既有
  颜色和 marker；新增曲线选择下一项可用样式，主动切换配色方案时才按当前曲线顺序统一重排；
- 保存 `.instplot` 时两类数据都嵌入项目并恢复原顺序、绑定和样式。最终数据文件格式选择只作用
  于由 Studio 管理的手动数据文件，绝不能覆盖或改写用户原来导入的 CSV、TSV、TXT、DAT 或 XLSX；
- 手动数据生成独立文件后仍保持 `manual` 来源身份，因而可在录入窗口恢复原始输入；不能因为
  它已有 CSV/XLSX 路径就退化成不可编辑的普通导入文件；
- 必须覆盖混合验收：先导入后录入、先录入后导入、两类来源交替增加、分别删除、清除全部、
  撤销/重做、切换配色、保存重开、外部文件缺失和 PDF/PNG/SVG 导出。

## 7. Error bar 与重复实验数据

- 实验数据的默认工作流不是要求用户预先计算 error，而是粘贴同一 X 下的多次原始测量；
- 对重复测量，Studio 计算每个 X 的均值，并提供误差类型：标准差 SD 或均值标准误 SEM；
- 默认建议使用 SD，并在界面清楚标明当前选择，不能只写含糊的“error”；
- 默认 error 明确定义为样本标准差
  `SD = sqrt(sum((y_i - mean)^2) / (n - 1))`，图中绘制 `mean ± SD`；它不是每个测量值
  偏离平均值的绝对大小，也不是最大偏差；
- 用户主动选择 SEM 时使用 `SEM = SD / sqrt(n)`，图中绘制 `mean ± SEM`；
- 每个 X 至少需要两个有效重复测量才能计算 SD/SEM；不足时应显示缺失误差并给出明确提示，
  不能将误差静默设为 0；
- 原始重复值必须保存在项目中，不能只保存均值和误差，以便重开后重新选择 SD/SEM；
- 仍支持已经算好的对称 Y error，即 `Y ± error`；
- 支持可选的对称 X error，即 `X ± error`；
- 没有误差列时生成普通 line/scatter；
- 误差必须为有限非负数，缺失误差只影响对应数据点；
- 非对称上下/左右误差延后，不在第一版增加四个额外误差列；
- error bar 创建时默认沿用所属数据系列颜色；用户可以独立修改误差棒颜色、线宽、线型和端帽
  宽度，图例必须同步反映实际误差棒样式。
- 双击误差棒可编辑端帽宽度、颜色、线宽和线型；编辑结果与预览、保存和导出共用同一属性。

### 7.1 自动范围与端点刻度修订（已完成）

- 已复现：误差棒参与自动范围时，当前实现只收集平均点的 X/Y 中心值，没有把 `x ± x_error`
  或 `y ± y_error` 纳入边界，因此靠近画布边缘的误差棒可能被裁切或没有合理留白；这不是用户
  输入问题。
- 自动范围必须先计算所有有效、可见误差棒端点，再基于完整端点范围添加正常 padding；Y error
  扩展 Y 范围，X error 扩展 X 范围，两者都必须测试，缺失值只跳过受影响的数据点。
- 对数轴必须使用误差端点检查正值条件，不能只检查平均点；端点不合法时给出明确错误或警告，
  不能静默生成错误范围。
- 已复现：范围 `0.45–0.7`、固定主刻度间隔 `0.05` 时，最大端点 `0.7` 因二进制浮点除法后
  `floor` 向下取整而被遗漏，只显示到 `0.65`；这不是端点刻度设计，也不是界面设置问题。
- 固定间隔刻度生成必须使用与数值尺度相关的容差判断端点，既包含数学上正好落在间隔网格上的
  最大值，也不能把真正超出范围的下一个刻度误加进来。
- 回归测试至少覆盖 `0.45–0.7 / 0.05`、负数到正数、小数步长、非整除最大值、极大/极小有限值，
  以及 X/Y error 同时存在时的自动范围、预览和 PDF/PNG 裁剪。

### 7.2 误差棒与图例样式联动（已完成）

- 已复现：修改误差棒颜色、线宽、线型或端帽宽度后，所属系列的 legend key 仍使用主曲线颜色和
  固定的 `0.7 pt` 实线绘制；当前仅保存了“该系列存在误差棒”的布尔值，没有把实际误差棒样式
  传入图例。这属于错误联动，不是用户设置问题。
- legend key 中的误差棒颜色、线宽、线型和端帽宽度必须来自与该数据绑定匹配的可见 ErrorBar
  对象；主曲线/marker 仍保持自己的样式，两者可以不同，但必须同时出现在同一个图例 key 中。
- 图例误差棒不按某个数据点的实际误差数值缩放；它只表达“该系列含误差棒”，因此竖向高度采用
  清晰、稳定的示意尺寸。
- 当前总高度仅 `6 pt`，在 `12 pt` 图例行高中显得过矮。新高度以图例 marker 的实际直径为
  基准，首选候选规则为“marker 高度 + 约 `4 pt`”，再限制在约 `9–10.5 pt` 范围内；没有
  marker 时使用标准 marker 尺寸作为基准。最终数值必须通过 85 × 65 mm 画布、不同 marker
  尺寸及 PDF 缩放视觉检查后确定，不能只凭常量猜测。
- 误差棒应在 marker 中心上下对称，并比 marker 总高度多约 `3–4 pt`；上下仍需留出图例行安全
  边距。端帽宽度使用对象设置，但限制在图例 key 可容纳的范围内，避免挤入文字。
- 产品最终默认值统一为曲线 `1.0 pt`、误差棒 `1.0 pt`；早期执行计划中的 `0.7 pt`
  只是技术验证参考值，并未冻结为产品默认。实际图例线宽始终跟随用户修改，不另设一套
  “图例粗细”，已有项目中的自定义线宽也不被迁移覆盖。
- 回归测试覆盖修改颜色、线宽、七种线型、端帽宽度、空心/实心 marker、纯散点和曲线＋点；
  画布、PDF/PNG、保存重开以及图例位于图内/图上/图右时必须一致。

### 7.3 导入文件的误差列绑定（已完成）

- 普通 CSV/TXT/XLSX 导入后，每个数据文件除 X、Y 列外，应提供紧凑的可选 `Y error` 和
  `X error` 列选择；默认均为“无”，不能因为存在第三列就擅自把它解释成误差。
- 选择 Y error 后立即创建或更新所属系列的误差棒；X error 可选。取消误差列时移除对应误差
  维度，但不能删除原始数据列或主曲线。
- error 列必须与对应 X/Y 逐行配对，允许缺失值但拒绝负数、非有限值和无法对应的长度；错误信息
  必须指出文件、列和问题类型。
- 每个系列保留自己的误差列绑定；同一文件包含多条 Y 曲线时不能共用或覆盖错误的 error 列。
- 入口放在左侧相应文件/系列卡片中，保持紧凑，不再弹出复杂的独立绑定窗口；选择后立即更新
  主图、图例、自动范围、保存项目和 PDF/PNG 导出。
- 必须测试一次导入、分批导入、同一文件多系列、删除单个文件、清除全部后重新导入、保存重开，
  以及只有 Y error、同时有 X/Y error 和取消 error 绑定。

### 推荐的重复测量粘贴布局

```text
数据组 A
X 测量 1:  1.0  2.0  3.0
X 测量 2:  1.1  2.1  3.1     （可选，用于 X error bar）
```

## 12. 最终 QA 后续规则（已实现并完成本机复核）

### 12.1 工具窗口层级

- 坐标轴、曲线、点、误差棒、图例、标注、配色、录入数据和出版检查属于**非模态工具窗口**；
  点击主图时保持打开，但不得使用系统级“永远置顶”覆盖其他应用。
- 普通窗口状态下，工具窗口可独立移动、缩放、关闭和重新聚焦；主窗口可以覆盖工具窗口，用户
  仍能通过窗口切换、再次打开对应对象或点击可见部分找回，不能因失焦自动销毁编辑状态。
- 切换到其他应用时，Studio 工具窗口不得继续压在其他应用之上；返回 Studio 后，已打开窗口
  及其未提交输入仍然存在。
- 未保存修改、文件冲突、覆盖确认和破坏性删除确认属于**模态对话框**，只需相对 Studio 主窗口
  保持在前并阻止冲突操作；不得把全部普通编辑窗口都提升为系统级置顶窗口。
- macOS 原生全屏及最大化状态继续使用主窗口内部的浮动回退，保证窗口不跨桌面空间、不丢失；
  退出全屏/最大化后恢复普通非模态窗口行为。
- 验收必须覆盖普通、最大化、全屏、点击画布、多窗口并存、切换到其他应用再返回，以及关闭并
  重新打开工具窗口；任何窗口不得永久遮挡主图、永久藏在主窗后或覆盖其他应用。
- 本规则取代 `INSTPLOT_STUDIO_PHASE7_UI_DESIGN_SYSTEM.md` 中“所有普通工具窗口统一置顶”的旧结论。

### 12.2 出版检查中的冗余视觉编码

- “仅用颜色区分”必须按**用户看到的一条完整图例系列**判断，不能分别把 line、marker 和
  error bar 当成互不相关的 artist 逐对检查。
- 两条使用不同颜色的系列，只要颜色之外至少存在一种清楚、稳定且会进入图例和导出的区别即可
  通过：marker 形状/实空/有无不同，或 line dash/有无线条不同；不要求 marker 和 line style
  同时都不同。
- 纯散点没有 line style 可用，因此应以 marker 形状、实空或其他明确点形编码区分；纯线图没有
  marker 时，应以 dash pattern 区分；line + marker 只要 marker 或 dash 任一通道不同即可。
- 线宽、marker 细微尺寸差和透明度不作为主要冗余编码，因为在最终印刷尺寸、灰度输出或视觉
  障碍场景中不够稳定。误差棒是否存在可以作为实验语义提示，但两条都有相同误差棒时不能据此
  视为已经区分。
- `color_only_encoding`、灰度可辨识度和色觉缺陷模拟应共享同一套“复合系列 + 非颜色签名”模型；
  若颜色在灰度或 CVD 模拟中接近，但 marker 或 dash 已明确不同，不应再误报为完全无法区分。
- 默认自动样式仍应尽量同时轮换颜色、marker 和线型，以提高辨识度；但出版检查的最低通过条件
  是“颜色 + 至少一种有效非颜色通道”，而不是强制三者全部不同。
- 回归用例至少覆盖：同色/不同色、纯线、纯散点、line + marker、实心/空心、相同 marker 但
  不同 dash、相同 dash 但不同 marker、error bar，以及图例、PDF/PNG/SVG 和保存重开一致性。

### 12.3 手动数据默认名称

- 新建和新增手动数据组的默认名称按创建序号使用 `Data N`，图例、左栏卡片、保存文件建议名及
  空名称回退必须一致，不再自动生成“手动数据 N”。
- 用户仍可主动修改为任意受文字管线支持的名称；默认英文命名不代表悄悄接受当前出版字体不支持
  的字符，最终图例和导出仍走既有字体与出版检查。
- 旧项目中用户已经保存的名称保持原样，不能在迁移或重开时擅自改名。
