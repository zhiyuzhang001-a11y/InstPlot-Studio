## 1. 目标

在不把 Studio 变成电子表格或增加主界面负担的前提下，补齐两类常见科研绘图需求：

1. 用户可以明确控制 marker 每隔多少个数据点显示一次；
2. line、line + marker、scatter 和 error bar 在图例中使用正确且不同的示意；
3. 用户可以直接录入或粘贴少量实验数据，包括同一 X 下的多次重复测量，并立即生成普通
   曲线、散点或 error bar。

## 2. Marker 数量与大小

- marker 默认在全部有效数据点上显示，即间隔为 1；
- 对象窗口提供“每隔 N 个点显示”，N 为正整数；N=1 表示全部显示，N=2 表示每两个点显示
  一个 marker；
- 抽样规则必须确定，首个数据点始终显示；是否强制显示末点需固定为同一规则，不能随预览尺寸变化；
- 少量散点使用稍大的 marker，保证辨识度；
- 点数很多的曲线可以使用较小 marker，但默认仍全部显示，由用户主动改变间隔；
- 线仍使用全部有效数据点，marker 仅做确定性抽样显示，不能改变数据或拟合结果；
- marker 大小可使用“小 / 标准 / 大”，line 与 scatter 可以有不同的默认大小；
- 空心/实心可应用到全部散点或点线系列，但只能改变填充状态，不能覆盖每条曲线自己的
  marker 形状、颜色、大小和显示间隔；
- 保存重开、PDF/PNG 和画布预览必须使用同一 marker 尺寸与抽样规则。

## 3. 图例必须反映实际图形

- line only：图例只画线段；
- line + marker：图例画线段，并在中央画实际 marker；
- scatter：图例只画 marker，不能带一条不存在的连接线；
- error bar：图例至少表达该系列的 marker/line 风格，并显示简洁的误差棒语义；
- 空心/实心、颜色、线型和 marker 形状必须与主图一致；
- marker 显示间隔只影响主图密度，不应让图例中的 marker 消失。

### 3.1 七种线型补充（已完成）

- 线型与七种颜色、七种 marker 使用一致的循环序号；
- 在现有实线、虚线、点线、点划线之外，增加长虚线、长短划线和双点划线；
- 三种新增线型必须在 85 × 65 mm 画布、细线、PDF 和常用缩放比例下仍能与现有线型明显
  区分；不能只靠非常接近的疏密变化；
- 图中曲线、图例、画布预览和 PDF/PNG 导出必须使用同一 dash pattern；
- 第一版不开放任意 dash 数组编辑，避免难以辨认或不适合出版的小间隔组合。

### 3.2 科研标注补充（已完成）

- 本轮不增加 inset axes，也不以普通方框伪装独立坐标区；多 axes/插图留到后续阶段单独设计。
- 普通文字标注支持在输入框中直接按 Enter 换行；多行排版、选择框、拖动、PDF/PNG 导出和保存
  重开必须一致。
- 增加统一的“连接线标注”对象，通过端点箭头模式覆盖普通连接线、末端箭头、起点箭头和双向箭头，
  不分别制造多套对象和窗口。
- 一段文字允许连接一支或多支箭头，适合一个物理量标签同时指向多个特征点。
- 文字位置和每个端点均可独立拖动；箭头端点可绑定数据坐标，使坐标范围改变后仍指向原数据点，
  文字位置可保留为画布坐标以方便排版。
- 连接线复用产品的颜色、线宽和七种线型；箭头大小提供受限范围，避免过大、过小或影响出版观感。
- 单击选中时显示不参与导出的端点控制柄；双击打开编辑窗口；支持复制、删除和前移/后移层级。
- 矩形、椭圆、高亮区域、花括号等通用矢量形状暂不进入第一版，避免把 Studio 扩张为通用绘图器。
- 验收覆盖单行/多行文字、无箭头/单箭头/双箭头、一段文字连接多箭头、轴范围改变后的数据锚定、
  保存重开、PDF/PNG，以及普通、最大化和全屏窗口。

## 4. 顶部“录入数据”入口

- 主界面顶部栏新增四字入口“录入数据”，不放入“文件”菜单；
- 窗口标题使用更完整的“录入或粘贴数据”；
- 同一窗口同时支持逐行键入和从 Excel、Origin、Word、文本文件等来源粘贴；
- 提交后形成正式 data source，例如“手动数据 1”，并进入现有左侧文件/数据区域；
- 手动数据与导入文件遵循相同的颜色、图例、删除、撤销、项目保存和导出规则。
- 完成绘图后，手动录入的数据像导入文件一样以独立数据源出现在左栏；清除全部数据后可重新
  录入，不依赖示例图或旧数据状态。

## 5. 粘贴格式兼容

优先复用现有文件导入中已经验证的分隔符检测与数值解析能力，不能再维护一套行为不同的粘贴
解析器。录入窗口只增加适合剪贴板的预览和列角色，不复制核心解析规则：

- 制表符：优先兼容 Excel、Origin 和表格软件复制内容；
- 逗号：兼容 CSV，并正确处理带引号字段；
- 分号：兼容部分地区和仪器软件的导出格式；
- 连续空格：兼容常见纯文本数据；
- 换行划分记录，空行自动忽略；
- 粘贴内容不识别表头；第一行始终作为数据处理；
- 出现文字表头或其他非数值内容时明确指出具体行列，让用户删除后重试，不进行猜测；
- 空单元格保留为缺失值，绝不能静默转换为 0；
- 小数逗号只在制表符或分号作为列分隔符时自动识别，避免与 CSV 逗号歧义；
- 分隔方式或小数格式存在歧义时必须显示预览并让用户确认，不能静默选错。

## 6. 录入模式

当前采用独立列录入，不再使用大矩阵和列角色选择：

- 默认一个 X 和一个 Y，X/Y 都可继续增加；
- 按钮文字明确为“＋重复测量（用于误差棒）”与“＋新增 X 组（用于多条曲线）”；前者参与
  SD/SEM 计算，后者建立采用独立横坐标的数据系列；
- 每个 Y 从列表中选择对应的 X；
- 每个 X/Y 可增加重复测量；一组数据直接绘制，两组及以上自动计算均值和 SD/SEM；
- 用户确认“绘图”后才一次性创建正式数据源、曲线和误差棒；取消不改变项目；
- 无法解析的数值、重复测量长度不一致和配对 XY 长度不一致会明确指出具体数据组。

## 6.1 独立列录入修订（2026-09-25）

- 录入窗口使用与对象编辑器相同的可移动、可缩放窗口规则；普通、最大化和全屏状态均不能
  丢失窗口，点击主画布也不能自动关闭；
- 不再要求用户把所有数据拼进一个大矩阵。X 与 Y 各自使用独立的名称和数据输入框；
- 默认提供一个 X 和一个 Y，并分别提供紧凑的“增加 X”“增加 Y”；X、Y 数量都不设为只能
  有一个；
- 每个 Y 明确选择与哪个 X 配对，因此支持一个 X 对多个 Y、多个 X 对多个 Y，以及多组各自
  独立的 XY 数据；
- 每个 X 或 Y 都可以增加重复测量输入框。只有一组数值时直接绘制原始值；两组及以上时自动
  逐点计算均值与样本 SD（或用户选择的 SEM），并自动生成相应 X/Y error bar；
- 每个输入框只负责一列数值，接受换行、Tab、空格、逗号和分号；不识别表头。非法数值、
  组内长度不一致或一对 XY 长度不一致时必须指出具体 X/Y 与测量编号；
- 多个 XY 组合一次提交，并作为一次完整操作成功或失败；自动分配不同颜色、marker 和图例名；
- 原始重复测量、均值和误差都保存在正式数据源中，不能只留下统计结果。

## 6.2 同批交互修订（2026-09-25）

- 坐标范围、主刻度间隔和副刻度间隔改为文本缓冲编辑：编辑时允许暂时为空，按 Enter 或失焦
  后才校验并应用，Esc 恢复；不能因实时更新导致用户无法删掉旧值；
- 数据文件区标题行的“清除全部”叉号移到左侧，并与每张文件卡片的删除叉号纵向对齐；
- marker 尺寸和显示间隔各自在右侧提供独立的“应用于全部曲线”复选框。默认只改当前曲线，
  两个属性不能互相覆盖，也不再使用额外的大按钮。

## 6.3 清除全部后的空白默认画布（已完成）

- “清除全部数据”不能保留已经删除数据的 XY label、坐标范围、主刻度间隔或副刻度间隔；这些
  数据相关状态必须一起重置，避免空画布继续表达旧实验含义。
- 清除后显示空白默认坐标框，而不是重新载入七条示例曲线：XY label 清空，X/Y 范围恢复
  `0–1`，主刻度和副刻度恢复自动。
- 保留与数据无关的产品规范，包括 85 × 65 mm 画布、四条 spine、四边向内刻度、字体和默认
  线宽；清除数据不应破坏出版样式。
- 再次导入或录入数据时，根据新选择的 X/Y 列重新生成标签、自动范围和刻度，不能继承被清除
  数据的状态。
- 删除单个文件时不能无条件重置全部坐标轴；应根据剩余可见系列重新自动缩放，并保留仍然有效
  的标签。清除全部必须作为一次可撤销操作，撤销后完整恢复数据和原坐标状态。

## 7. Error bar 与重复实验数据

- 实验数据的默认工作流不是要求用户预先计算 error，而是粘贴同一 X 下的多次原始测量；
- 对重复测量，Studio 计算每个 X 的均值，并提供误差类型：标准差 SD 或均值标准误 SEM；
- 默认建议使用 SD，并在界面清楚标明当前选择，不能只写含糊的“error”；
- 默认 error 明确定义为样本标准差
  `SD = sqrt(sum((y_i - mean)^2) / (n - 1))`，图中绘制 `mean ± SD`；它不是每个测量值
  偏离平均值的绝对大小，也不是最大偏差；
- 用户主动选择 SEM 时使用 `SEM = SD / sqrt(n)`，图中绘制 `mean ± SEM`；
- 每个 X 至少需要两个有效重复测量才能计算 SD/SEM；不足时应显示缺失误差并给出明确提示，
  不能将误差静默设为 0；
- 原始重复值必须保存在项目中，不能只保存均值和误差，以便重开后重新选择 SD/SEM；
- 仍支持已经算好的对称 Y error，即 `Y ± error`；
- 支持可选的对称 X error，即 `X ± error`；
- 没有误差列时生成普通 line/scatter；
- 误差必须为有限非负数，缺失误差只影响对应数据点；
- 非对称上下/左右误差延后，不在第一版增加四个额外误差列；
- error bar 创建时默认沿用所属数据系列颜色；用户可以独立修改误差棒颜色、线宽、线型和端帽
  宽度，图例必须同步反映实际误差棒样式。
- 双击误差棒可编辑端帽宽度、颜色、线宽和线型；编辑结果与预览、保存和导出共用同一属性。

### 7.1 自动范围与端点刻度修订（已完成）

- 已复现：误差棒参与自动范围时，当前实现只收集平均点的 X/Y 中心值，没有把 `x ± x_error`
  或 `y ± y_error` 纳入边界，因此靠近画布边缘的误差棒可能被裁切或没有合理留白；这不是用户
  输入问题。
- 自动范围必须先计算所有有效、可见误差棒端点，再基于完整端点范围添加正常 padding；Y error
  扩展 Y 范围，X error 扩展 X 范围，两者都必须测试，缺失值只跳过受影响的数据点。
- 对数轴必须使用误差端点检查正值条件，不能只检查平均点；端点不合法时给出明确错误或警告，
  不能静默生成错误范围。
- 已复现：范围 `0.45–0.7`、固定主刻度间隔 `0.05` 时，最大端点 `0.7` 因二进制浮点除法后
  `floor` 向下取整而被遗漏，只显示到 `0.65`；这不是端点刻度设计，也不是界面设置问题。
- 固定间隔刻度生成必须使用与数值尺度相关的容差判断端点，既包含数学上正好落在间隔网格上的
  最大值，也不能把真正超出范围的下一个刻度误加进来。
- 回归测试至少覆盖 `0.45–0.7 / 0.05`、负数到正数、小数步长、非整除最大值、极大/极小有限值，
  以及 X/Y error 同时存在时的自动范围、预览和 PDF/PNG 裁剪。

### 7.2 误差棒与图例样式联动（已完成）

- 已复现：修改误差棒颜色、线宽、线型或端帽宽度后，所属系列的 legend key 仍使用主曲线颜色和
  固定的 `0.7 pt` 实线绘制；当前仅保存了“该系列存在误差棒”的布尔值，没有把实际误差棒样式
  传入图例。这属于错误联动，不是用户设置问题。
- legend key 中的误差棒颜色、线宽、线型和端帽宽度必须来自与该数据绑定匹配的可见 ErrorBar
  对象；主曲线/marker 仍保持自己的样式，两者可以不同，但必须同时出现在同一个图例 key 中。
- 图例误差棒不按某个数据点的实际误差数值缩放；它只表达“该系列含误差棒”，因此竖向高度采用
  清晰、稳定的示意尺寸。
- 当前总高度仅 `6 pt`，在 `12 pt` 图例行高中显得过矮。新高度以图例 marker 的实际直径为
  基准，首选候选规则为“marker 高度 + 约 `4 pt`”，再限制在约 `9–10.5 pt` 范围内；没有
  marker 时使用标准 marker 尺寸作为基准。最终数值必须通过 85 × 65 mm 画布、不同 marker
  尺寸及 PDF 缩放视觉检查后确定，不能只凭常量猜测。
- 误差棒应在 marker 中心上下对称，并比 marker 总高度多约 `3–4 pt`；上下仍需留出图例行安全
  边距。端帽宽度使用对象设置，但限制在图例 key 可容纳的范围内，避免挤入文字。
- 产品最终默认值统一为曲线 `1.0 pt`、误差棒 `1.0 pt`；早期执行计划中的 `0.7 pt`
  只是技术验证参考值，并未冻结为产品默认。实际图例线宽始终跟随用户修改，不另设一套
  “图例粗细”，已有项目中的自定义线宽也不被迁移覆盖。
- 回归测试覆盖修改颜色、线宽、七种线型、端帽宽度、空心/实心 marker、纯散点和曲线＋点；
  画布、PDF/PNG、保存重开以及图例位于图内/图上/图右时必须一致。

### 7.3 导入文件的误差列绑定（已完成）

- 普通 CSV/TXT/XLSX 导入后，每个数据文件除 X、Y 列外，应提供紧凑的可选 `Y error` 和
  `X error` 列选择；默认均为“无”，不能因为存在第三列就擅自把它解释成误差。
- 选择 Y error 后立即创建或更新所属系列的误差棒；X error 可选。取消误差列时移除对应误差
  维度，但不能删除原始数据列或主曲线。
- error 列必须与对应 X/Y 逐行配对，允许缺失值但拒绝负数、非有限值和无法对应的长度；错误信息
  必须指出文件、列和问题类型。
- 每个系列保留自己的误差列绑定；同一文件包含多条 Y 曲线时不能共用或覆盖错误的 error 列。
- 入口放在左侧相应文件/系列卡片中，保持紧凑，不再弹出复杂的独立绑定窗口；选择后立即更新
  主图、图例、自动范围、保存项目和 PDF/PNG 导出。
- 必须测试一次导入、分批导入、同一文件多系列、删除单个文件、清除全部后重新导入、保存重开，
  以及只有 Y error、同时有 X/Y error 和取消 error 绑定。

### 推荐的重复测量粘贴布局

```text
X    测量1    测量2    测量3
1.0  2.11     2.08     2.14
2.0  3.02     2.97     3.05
```

实际粘贴时不包含上面的文字表头，只粘贴数值。第一列作为 X，其余列作为同一组重复测量；软件
预览均值和 SD/SEM 后再绘制。若用户想粘贴多条彼此独立的 Y 曲线，应选择普通 X/Y 或以后单独
设计“多系列”模式，不能把独立曲线误当重复测量。

## 8. 验收重点

- 3、10、100、1,000 和 10,000 点分别验证 marker 间隔 1、2、5、10；默认必须为 1；
- 同一项目保存重开、PDF/PNG 导出后 marker 数量、位置和大小一致；
- 分别验证 line、line + marker、scatter、error bar 的图例样式；
- 分别粘贴 tab、CSV、分号、空格、小数逗号、纯数值和含意外文字的数据；
- 验证普通 X/Y、预计算 error、重复测量 SD、重复测量 SEM 和含部分缺失重复值；
- 非法输入必须给出精确错误，取消或失败不得留下半个数据源；
- 普通、最大化和全屏状态下窗口均可见、可操作、可关闭和找回。

## 9. 明确不做

- 不提供完整电子表格、公式、单元格格式或多工作表编辑；
- 不把入口放回文件菜单；
- 不在第一版支持非对称误差、协方差或通用统计分析；
- 不自动识别或猜测粘贴数据中的表头；
- 不把多条独立 Y 曲线自动解释为重复测量；只有用户在同一 X/Y 数据组内主动增加的“重复测量”才参与 SD/SEM；
- 不因 marker 抽样删除或修改原始数据点。
- 本轮不增加双 Y 轴；左右独立纵坐标、系列轴绑定和双轴合并图例留到后续单独计划。
