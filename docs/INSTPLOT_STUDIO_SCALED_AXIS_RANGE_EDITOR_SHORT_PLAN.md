# InstPlot Studio 倍率感知的坐标范围编辑短计划

> 配套执行计划：`INSTPLOT_STUDIO_SCALED_AXIS_RANGE_EDITOR_IMPLEMENTATION_PLAN.md`
> 状态：`COMPLETED — AUTOMATED GATES AND INDEPENDENT REAL-UI QA PASS`
> 日期：2026-09-28
> 范围：改善坐标范围、主刻度和副刻度等数值编辑，并统一所有数据变化后的 autoscale 生命周期；不修改 `{scale}`、轴标签排版、原始数据或现有倍率模型。

## 1. 已确认不修改

- 保留 `{scale}` 的现有语义和行为。
- 用户继续通过 `{scale}` 精确决定 `×10ⁿ` 在轴标签中的位置。
- 不自动猜测 `Ω / mΩ / μΩ` 等单位，也不自动改写轴标签。
- 原始数据、误差值、参考线坐标、测量对象坐标和项目中保存的轴范围仍使用真实原始数值。
- 不增加新的项目 schema；本功能只改变编辑器的显示与输入换算。

## 2. 核心修改

当某条轴的有效显示指数为 `n` 时，坐标轴数值编辑器默认使用画面上看到的系数值：

```text
显示值 = 原始值 / 10ⁿ
原始值 = 输入值 × 10ⁿ
```

例如轴使用 `×10⁻³`：

- 原始范围 `−0.0039 … 0.0095` 在编辑器中显示为 `−3.9 … 9.5`。
- 原始主刻度间隔 `0.0025` 显示并输入为 `2.5`。
- 提交 `最大值 = 10` 时，项目内部保存 `0.010`。
- 图上刻度、范围编辑器和轴标签使用同一倍率含义。

这只是显示坐标与编辑输入的换算，不改变数据源中的真实值。例如真实值 `0.005 Ω` 仍保存为 `0.005 Ω`，界面仅将它显示为系数 `5`，并由轴标签说明 `×10⁻³ Ω`。

需要同步倍率化的字段：

- 最小值、最大值。
- 固定主刻度间隔。
- 固定副刻度间隔。
- Fixed locator 的刻度值列表。
- X1、Y1、X2、Y2 的状态分别独立处理；按产品现有模式分别验证单轴、双 X（X1/X2/Y1）和双 Y（X1/Y1/Y2），不构造同图 X2+Y2 四轴状态。

范围限定为“倍率化现有编辑入口”。实施前先列出范围、主间隔、副间隔和 Fixed ticks 在 X1/Y1/X2/Y2 上的实际入口矩阵；若某条副轴当前没有某项编辑入口，本次不借机新增完整 locator 编辑器，除非另行确认。

实施核对后的入口矩阵：X1、Y1、X2、Y2 的现行快速编辑器均提供范围、主间隔和副间隔，因此三类字段已统一倍率化；当前产品没有对外启用 Fixed ticks 编辑入口（旧完整编辑器代码不在现行窗口路径中），本轮按冻结范围不新增该 UI。已有项目中的 Fixed locator 仍可读取、保存、布局，并会在数据语义变化时按统一合同恢复为 Auto；其解析语义继续由既有回归测试保护。

## 3. 界面规则

- 范围窗口在字段同组位置紧凑显示轴身份和当前输入尺度，例如：`Y2 输入尺度：×10⁻³`。
- `None` 或有效指数为零时按原值输入，不显示多余说明。
- `ManualFactor` 使用其固定指数。
- `ManualIncorporated` 使用其冻结指数，并提示“倍率已写入轴标签单位；软件不校验单位文字与指数是否匹配”。
- `AutoFactor` 使用正式 layout 当前解析出的指数，不另写一套判断算法。
- AutoFactor 只能读取与当前呈现 frame、当前 `AxisIdentity` 和当前文档版本对应的 resolved exponent；不得根据 range、数据或 formatter 在 UI 层重新推导。
- 隐藏轴、空副轴、无数据、layout 尚未完成或失败时，优先保留该轴最后一次有效 resolved exponent；若没有可验证的指数，则禁用倍率感知提交并显示原因，不能静默另算。
- 自动范围开启时，范围字段继续只读，但显示倍率换算后的数值。
- 输入框继续采用延迟提交：允许暂时清空；Enter 或失焦后再验证并提交。
- 每次有效提交保持一次 Undo；非法、溢出或非有限换算不得改变文档。
- 示例和字段默认使用 ASCII `-` 作为可输入负号；若接受 Unicode `−/–`，必须在解析前统一规范化并测试。

## 4. 自动倍率的稳定边界

AutoFactor 的指数可能随范围改变，因此编辑期间必须避免字段含义跳变：

1. X1、Y1、X2、Y2 分别维护自己的编辑会话和冻结指数，不得共用草稿状态。
2. 同一轴的第一个相关字段获得焦点时，冻结当时正式 resolved layout 的有效指数。
3. 只要该轴任一字段仍聚焦或存在 dirty 草稿，就不刷新该轴任何数值文本，也不改变这些草稿的解释尺度。
4. Enter 或失焦只提交当前字段；Escape 恢复该字段获得焦点前的显示值，不产生 Undo。
5. 当该轴已无聚焦或 dirty 字段时，会话才结束；此时重新 layout，并统一刷新全部显示值和尺度说明。
6. 切换轴身份、倍率模式、线性/对数类型、单轴/双轴模式、关闭窗口、打开项目以及 Undo/Redo 时，不得将旧草稿按新指数解释。实施时选择明确一致的“取消草稿”规则；不做隐式提交。
7. 如果范围提交导致 AutoFactor 指数改变，先使用被冻结的指数完成本次 `display → raw` 换算，再以新 layout 指数刷新下一次显示。
8. 另一窗口的数据事务成功后，必须取消受影响轴未提交的范围、主/副刻度草稿，结束其冻结指数会话，并用新 layout 同步字段；数据事务失败时保留原草稿。

## 5. 数值与轴类型边界

- 所有入口共用唯一的 `raw ↔ display` 换算 helper，UI draft、EditCommand、document 和序列化层不得重复乘除。
- 线性轴：范围和 interval 按上述倍率双向换算。
- 对数轴：范围值同样可以按倍率显示；换算后的原始最小值和最大值仍必须为正。
- factor、输入和结果都必须有限；`10ⁿ` 下溢为零、上溢为无穷，或乘除结果为 NaN/∞ 时拒绝提交并显示中文原因。
- 显示值换回 raw 后，才执行现有领域验证：最小值小于最大值、对数轴为正、interval 为有限正数、tick 数量不超过上限。
- Fixed ticks 先整批解析，再整批换算和验证，并通过一个原子事务提交；任一 token 或任一换算失败时全部保持不变。本次不改变其既有排序、重复值、范围外值或分隔符语义。
- 极小值、极大值、负值、跨零范围以及大偏置小跨度不得因显示换算丢失精度。
- 显示文本需要足够精度，重新打开窗口不能因格式化造成原始范围漂移。
- 打开、关闭或刷新窗口不得写回未编辑字段；只修改一个字段时，不得因重新格式化连带写回其他字段。
- no-op 提交不生成 Undo，不能只因文本形式不同而重写相同 raw bits。
- 极端指数不是无条件成功：factor 和换算结果可表示且能保持有效范围时才成功；如果两个不同输入舍入成同一 raw 值，则拒绝而不是静默接受退化范围。

## 6. 数据变化后的 autoscale 统一规则

### 6.1 已确认的现状与根因

2026-09-28 的真实操作已稳定复现：录入数据已从旧数值更新为 `X = 0…5`、`Y = 1000…120000`，但 Y1 仍保留旧手动范围 `-0.01…0.0094496`和旧固定主刻度间隔 `0.00388994`，因此新数据全部落在画布外。数据解析、数据源更新和曲线绑定本身均已成功。

根因是现有 `refresh_autoscale()` 只刷新 `axis.autoscale == true` 的轴；轴一旦被用户手动设置过范围，后续录入数据修改虽然调用了 `refresh_autoscale()`，也会被直接跳过。这是数据变化生命周期不完整，不是数值解析失败。

以往测试只覆盖了“autoscale 本来就开启”和“删空后重新导入文件”，没有覆盖最关键的真实路径：`手动范围 → 数据内容或绑定变化 → 数据跨度变化`。后续不再为单个入口打补丁，而是建立一条共用规则。

### 6.2 统一行为契约

- 任何成功改变可见曲线数值含义的操作，都使与该曲线绑定的轴进入新的数据上下文，并在最终数据源、series、误差列和轴绑定全部确定后执行一次 autoscale。
- 数据变化明确优先于旧的手动范围：受影响轴必须重新设为 `autoscale = true`，不得因旧状态为 `false` 而跳过。
- 为保证新数据一定可正常呈现，受影响轴的主刻度 locator 恢复为 `Auto { target_count: 6 }`，副刻度间隔恢复为自动，formatter 恢复为 `Auto`。不能让与旧量级绑定的固定间隔、Fixed ticks 或固定小数精度破坏新范围。display-scale 模式仍保留。
- “受影响轴”按操作前后可见数据贡献者的并集确定。换列、更换来源、轴迁移和删除同时考虑旧绑定与新绑定；例如 Y1→Y2 时 Y1 和 Y2 都要更新。
- 每条受影响轴必须聚合该轴上所有当前有效且可见的数据曲线、有限误差端点和明确纳入 autoscale 的参考线，不能只根据刚修改的曲线计算。
- 数据变化不重置轴标签的用户自定义内容、字体、字号、labelpad、spine 样式、刻度样式、颜色和线宽。只有仍然等于旧绑定列名的自动标签才随新列名更新；用户自定义标签必须保留。删除全部数据后首次导入可重建自动列名标签。
- 保留用户选择的线性/对数轴类型；若新数据不满足对数轴正值要求，用中文说明原因并原子回滚，不静默改成线性轴。
- 数据创建、删除、更换、换列、误差列或轴绑定变化，以及数据曲线的显示/隐藏，都会改变范围贡献者。修改颜色、marker、linestyle、图例、文字、参考线样式等不应强制开启 autoscale。
- 隐藏曲线不贡献范围；修改完全隐藏的曲线时不立即改变画布范围，重新显示时再 autoscale。图例显示/隐藏不影响 autoscale。
- `include_in_autoscale = true` 的参考线继续参与已开启的 autoscale；移动参考线、改变其样式或可见性不属于新数据上下文，不得强制把手动轴切回 autoscale。测量箭头和普通标注继续不参与 autoscale。
- 删除一部分数据后，其余可见曲线所绑定的受影响轴重新 autoscale。某条轴变空但图中仍有其他数据时，线性轴使用 `0…1`，对数轴使用 `1…10`，保持当前单/双轴模式和空副轴占位规则。删除最后一个数据源后才执行现有整图清空契约。
- 打开项目、保存和导出不是数据变化，不得重新强制 autoscale；项目打开应恢复已保存快照。
- 单个文件导入或一次录入数据提交是原子事务；解析、绑定、误差列验证、autoscale、layout 或预览任一失败，该事务不得留下半成品状态。批量导入沿用现有“按文件原子、允许部分成功”的语义，autoscale 以最终成功接受的数据集合计算。
- 文件导入和录入数据提交保持现有历史基线/rebase 语义，不借本次修改重构 Undo 系统；换列、误差列、删除等现有编辑命令继续按原有规则产生 Undo。Undo 恢复完整旧快照（包括手动范围、locator 和 autoscale 状态），Redo 恢复已计算的新快照，二者都不得再次触发 autoscale。

### 6.3 必须纳入的数据变化入口

- 录入数据：首次绘图、修改已保存数据组、新增 XY 组、新增重复测量、更改 X/Y 数值、更改 SD/SE 统计和全部清除后重新录入。
- 导入文件：首次导入、追加单个或多个文件、同一文件替换/重新导入、删除后重新导入、一个文件内多列数据，以及所有现有导入格式的共用完成路径。
- 曲线绑定：从已有数据源创建新曲线，更换 X 列、Y 列、X/Y 同时更换、更换数据源、曲线迁移到 X2/Y2 或迁回 X1/Y1，以及数据曲线的显示/隐藏。
- 误差数据：添加、更换或删除 X error/Y error，以及重复测量生成的误差端点变化。
- 删除数据：删除单组、多组、某文件、关联 fit/依赖来源和最后一个数据源；Undo/Redo 作为快照恢复回归，不视为新数据变化入口。

### 6.4 autoscale 回归矩阵

- 数值跨度：小→大、大→小、全正、全负、跨零、常数列、大偏置小跨度、极小值和极大值。文件中的缺失值、无效行、NaN 和 alive mask 继续沿用现有过滤规则；数据列无有限贡献者时按 6.2 的空轴规则处理，误差端点计算溢出为非有限值时仍原子失败。
- 起始轴状态：autoscale 原本开启、手动范围、固定主刻度间隔、Fixed ticks、固定副刻度间隔、线性轴、对数轴和倍率显示模式。
- 数据来源：录入数据、各现有文件格式的导入 smoke test、文本族与工作簿族各至少一条完整生命周期，以及同时存在的录入数据与导入文件、单数据组与多数据组。不做“所有格式×所有轴×所有误差模式”的笛卡尔积。
- 轴绑定：X1/Y1、X2/Y1、X1/Y2，以及不同曲线分布在主轴/副轴时只刷新受影响轴。
- 误差：无误差、X error、Y error、XY error、重复测量 SD/SE；断言范围包含有限误差端点而不是只包含平均点。
- 可见性与辅助对象：多曲线共轴、隐藏曲线修改后重新显示、图例显隐、参考线纳入/不纳入 autoscale、测量箭头和普通标注不参与。
- 批量导入：一个有效文件＋一个无效文件、多文件顺序、fit 文件先于来源文件，验证部分成功语义与最终 autoscale 结果。
- 事务边界：导入/录入 rebase 不产生半成品历史记录；可 Undo 的编辑命令沿用现有步数契约；失败、取消和 no-op 不改变历史；Undo/Redo、保存重开和导出后的范围与数据绑定一致。
- 标签保护：自定义标签后修改录入数据不被列名覆盖；自动列名标签随换列更新；双 X/双 Y 各轴独立；全部清空后首次导入允许重建自动标签。
- 草稿竞态：受影响轴存在未提交的倍率范围/刻度草稿时提交数据，成功则取消草稿并同步新布局，失败则保留草稿。
- 真实 UI 路径：用窗口操作重现 `手动范围 → 修改录入数据 → 绘图`、`手动范围 → 更换 XY 列`、`手动范围 → 重新导入`，验证画布内所有有限数据及误差端点都可见，而不只检查 document 字段。

## 8. 误差棒回归不变量

- 误差棒中心、`y ± σ` / `x ± σ` 端点、标准差、标准误和显式误差列继续保持真实数据坐标；倍率切换前后这些 raw 值和映射几何不变。
- X error 继续绑定 X1/X2，Y error 继续绑定 Y1/Y2；分别在双 X（X1/X2/Y1）和双 Y（X1/Y1/Y2）模式测试轴隔离，但误差棒几何本身不消费显示指数。
- autoscale 继续使用真实有限误差端点；本次只验证范围编辑器显示的是 autoscale 结果除以当前轴 factor 后的数值。

- 对数轴非正误差端点沿用当前既有处理；本次不重新决定拒绝、裁剪或警告策略。

## 9. 验收重点

- `×10⁻³` 下可直接用 `−3.9、9.5、2.5` 编辑范围和间隔，画布与内部原始值正确。
- 指数 `0、−3、4` 覆盖常规行为；`−323、308` 仅在 factor 和换算结果可表示时成功，否则明确、原子地拒绝。
- 覆盖 `f64::MIN_POSITIVE`、最小 subnormal、`f64::MAX`、正负零和相邻浮点数；验证大偏置小跨度换算后仍可区分。
- AutoFactor 编辑期间不跳指数，提交后可以安全刷新为新的自动指数。
- X1、Y1、X2、Y2 的倍率和输入互不串扰；单轴、双 X、双 Y 均可使用。
- 自动/手动范围切换、None/Auto/ManualFactor/ManualIncorporated 切换后字段立即一致。
- 现行范围、主刻度间隔和副刻度间隔不会混用原始值与显示值；Fixed locator 因当前没有对外编辑入口，本轮不新增倍率输入 UI。
- Fixed ticks 继续覆盖既有解析、项目往返、布局及数据变化后恢复 Auto 的语义；未来若重新开放编辑入口，必须接入同一倍率 helper 后再交付。
