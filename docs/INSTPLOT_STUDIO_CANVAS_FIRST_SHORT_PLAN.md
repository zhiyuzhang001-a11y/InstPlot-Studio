# InstPlot Studio 画布优先界面短计划

> 状态：ACTIVE（Q0 DONE；Q1 已开始）
> 阶段代号：B5Q（B5P 完成后的交互简化阶段）
> 制定日期：2026-09-23
> 范围：只重组 Studio 界面与交互，不连接 Lite、不发布

## 目标

默认只呈现科研图形和一条极简菜单。用户点击 legend、曲线、marker、error bar、annotation、
坐标轴或标签后，在对象附近直接编辑；低频结构、数据与完整检查信息按需展开。

底层 Figure Document、resolved Display List、EditHistory、保存、Publication Check 和导出合同继续
作为唯一事实来源，不建立第二套临时编辑模型。

## Q0：画布优先框架

- 图层/数据与 Inspector 默认隐藏，可从顶部按需切换；
- 移除常驻缩放工具条、帧缓冲说明和自动占位的消息面板；
- 保留滚轮缩放、拖动画布；双击空白处适合窗口；
- 悬停可编辑对象时给出轻量高亮和指针反馈；
- 点击对象后在点击位置附近打开上下文编辑窗；点击空白或按 Escape 关闭；
- Publication Check 和运行时消息只以紧凑徽标提示。

完成条件：默认首屏只保留画布与极简顶栏；现有保存、撤销、检查和导出能力仍可达。

完成记录（2026-09-23）：默认隐藏两侧面板和消息区，移除常驻缩放条与帧缓冲说明，首屏自动
适合窗口；滚轮缩放、拖动、双击空白 Fit、悬停反馈、点击对象编辑、Escape/空白关闭均已接通。
轴标签与四条 spine 已进入正式 hit map，不再依靠界面坐标猜测；图层/数据、完整 Inspector、
Publication Check 和运行时消息仍可从顶部紧凑入口打开。

## Q1：逐对象直接编辑

- line、marker、error bar、reference line：样式与语义角色；
- legend：位置、条目显示与顺序、标签；
- annotation：位置与文本；
- xlabel/ylabel：语义文本；
- tick、spine、axis：范围、格式、刻度与间距；
- 重叠对象提供小型候选列表，不让命中顺序成为隐式行为。

完成条件：常用对象无需打开常驻 Inspector，也不需要手工寻找对象 ID。

## Q2：按需抽屉与高效操作

- 图层/数据抽屉负责精确选择、导入、绑定、新增、复制、排序与删除；
- 检查抽屉只在用户点击徽标时出现，finding 点击后定位并打开对象编辑窗；
- 编辑窗提供“更多…”与“固定为侧栏”，默认只显示高频属性；
- 补齐键盘焦点、Enter/Escape、Undo/Redo、Fit/100% 快捷操作。

完成条件：新用户可直接点击编辑，高级用户仍能完成全部 V1 操作。

## Q3：稳定化与关闭

- 验证窄窗口、长标签、重叠对象、小 marker、画布边缘弹窗定位；
- 验证连续编辑合并、dirty/save point、保存重开和导出一致性；
- 运行统一 B5P 审计并增加画布优先状态测试；
- 完成 macOS 人工界面检查；Windows 只在发布前做必要复核。

完成条件：简洁模式不丢功能、不绕过 EditHistory、不改变 PDF/PNG 输出合同。

## 明确不进入本阶段

- Lite producer/launcher 集成；
- 安装包、签名、公证和正式发布；
- 多 axes、3D、任意矢量编辑器能力。
