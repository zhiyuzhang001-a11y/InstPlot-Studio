# InstPlot Studio 画布优先界面短计划

> 状态：BASELINE DONE（Q0–Q3 的画布优先能力已形成基线；2026-09-24 后的多文件与界面收尾转入 B5R）
> 阶段代号：B5Q（B5P 完成后的交互简化阶段）
> 制定日期：2026-09-23
> 范围：只重组 Studio 界面与交互，不连接 Lite、不发布

## 目标

默认只呈现科研图形和一条极简菜单。用户点击 legend、曲线、marker、error bar、annotation、
坐标轴或标签后，在对象附近直接编辑；低频结构、数据与完整检查信息按需展开。

底层 Figure Document、resolved Display List、EditHistory、保存、Publication Check 和导出合同继续
作为唯一事实来源，不建立第二套临时编辑模型。

## 当前情况与 Q1 讨论稿

- Q0 已完成：画布占据默认首屏；点击对象可弹编辑窗，滚轮缩放、空白双击 Fit、图层/数据与完整
  Inspector 按需出现。现有窗口仍直接复用旧 Inspector 的大段表单，轴窗口尤其拥挤。
  Q1 将编辑手势改为双击，单击只选中。
- 当前四边 spine 和刻度默认显示，刻度默认朝内；但轴表单还提供朝外/内外各半、各种间距、
  刻度显示等选项。用户已明确刻度不提供朝外，刻度线长/线宽沿用默认值；其他轴对象具体
  保留哪些操作仍待逐项讨论。
  旧项目数据的读取兼容性须保留，不能因隐藏控件而静默损坏历史文件。
- 图例与 annotation 已有以图幅点为单位的 `x_pt/y_pt` 存储和可撤销编辑，但目前只能在表单
  中输入位置；画布命中只处理点击，拖动仍由滚动区用于平移。
- 坐标轴刻度目前只有自动定位和手工列出固定值，尚无 Matplotlib `MultipleLocator(1)` 那种
  固定间隔模式。默认自动刻度继续优先；固定主刻度间隔作为明确需要时才出现的选项。
- 小窗的原则：只放该对象最常改的内容。用户希望图例和 annotation 可直接拖动位置；窗口中
  是否保留 `x_pt/y_pt` 数值、各对象哪些设置归入“更多”仍待讨论。

## Q1 已确认的对象规则（2026-09-23）

- 字号暂时全部使用产品默认，不在小窗或完整 Inspector 中提供字号控制。当前布局默认值为
  X/Y axis label 共用 9 pt，X/Y tick label 共用 8 pt，legend 和 annotation 各为 8 pt。
  这些是当前产品实现值，不把它们解释成所有期刊的强制标准。将来如需开放字号，X/Y label
  必须联动、X/Y tick label 必须联动；legend 才可独立调整，但须先用 85 × 65 mm 样张
  确定合理上下限和防重叠检查，不能提供无界任意值。
- 新图不绘制 major/minor grid，小窗及完整 Inspector 均不提供 grid 开关。总计划 Part A
  的测试基线已写明 grid off；当前 Studio 的 `grid_major: true` 默认值与此不一致，实施 Q1
  时须改为 off，并审查旧项目的读取/迁移路径，避免隐藏开关后留下无法移除的历史网格。
- legend 只绘制图例项与文字，不绘制外框，也不绘制白色底板；仍保留不可见的逻辑命中范围，
  用于点击、拖动、自动放置和重叠检查。当前渲染器还会画半透明白底及灰色外框，需在 Q1
  实施时移除。
- 曲线/marker 继续遵循已完成的 P5 与 Part A 颜色合同：source 默认 marker，fit/theory
  默认 line；同一 source/fit 默认共享对象颜色，通过 marker/实线/虚线等非颜色线索区分；
  颜色来自有来源、版本和精确色值的 publication palette（Tol Bright、Tol High Contrast、
  发散色和中性灰）。显式改变某个 artist 的颜色仍允许，但要保留 override/provenance，
  不可悄悄破坏关联；灰阶/CVD 可读性继续由 Publication Check 覆盖。
- 刻度只有朝内方向；线长、线宽及原有布局间距沿用默认，不提供产品编辑控件。

## Q1：逐对象直接编辑

以下是剩余实施候选；上节已确认的规则不得被“更多设置”绕开。先讨论各对象的小窗字段，
再按定稿实现。

- Q1a 小窗瘦身：点击 xlabel/ylabel 只编辑文字；点击 X/Y 刻度或 spine 只显示该轴范围、自动
  刻度与可选主刻度间隔；点击曲线只显示 palette 颜色、线型及适用的线宽，点击 marker 只显示
  palette 颜色、形状与尺寸，点击 error bar 只显示其常用设置；图例显示条目文字、显隐与顺序；
  annotation 显示文字。高级、但仍允许的属性通过“更多设置”进入完整面板；字号、grid、
  刻度方向、刻度线长和刻度线宽不出现在产品编辑界面。
- Q1b 画布直接移动：按住 legend 或 annotation 拖动即实时预览位置，拖完记录为一次 Undo；
  单击只选中，双击才打开小窗，拖动不误开窗口。缩放、平移、窗口边缘和图幅边界都必须正确处理。
- Q1c 刻度间隔：为线性轴补充正式的固定主刻度间隔；次刻度在默认状态自动推导，只有明确
  调整时才显示附加字段。对数轴维持适合自身的自动 decade 刻度；项目格式、布局、预览、
  PDF/PNG 使用同一定位结果。
- Q1d 重叠命中：图例、文字、数据对象重叠时提供简短候选列表，避免只能选到最上层对象。

实施记录（2026-09-23）：新图 grid 关闭，历史 grid/朝外刻度仅保留读取而不进入渲染；legend

## 2026-09-23 界面补充定稿

- 标签普通文字、数字、单位和关系运算符（包括 `<=` → `≤`）不需要 `$`；
  上下标及符号也可在 `$` 外输入。只有显式斜体变量或手动限定数学片段时才用 `$...$`。
  所有示例、帮助和可编辑回显必须遵守同一规则。
- 顶部仅有“文件”“编辑”；导入、保存、导出图片在“文件”，视图缩放、语言、面板等
  保留功能归“编辑”。画布尺寸默认 85 × 65 mm，可手动调节，不给 89 × 65 mm 快捷预设。
- 对象编辑窗默认更宽且可移出主窗口；轴范围的最小/最大值并排。macOS 全屏和 Windows
  最大化时不得让窗口丢失或无法找回；无多窗口支持时使用嵌入回退。
- 鼠标滚轮缩放视图；触控板双指滚动平移、捏合缩放。上述操作不改变物理画布尺寸。
- 第一版不新建参考线；已有项目中的参考线必须保留读取和显示。图例、标注既能按住拖动，
  也能在小窗以距画布左/顶的毫米坐标精确定位，并保持两种操作同步。
- 产品示例包含多条曲线，以便检验颜色、marker、线型和图例；固定 Part A 回归样图
  不能被示例扩充污染。产品示例使用完整 Tol Bright 七色加一档独立中性灰，保留明确来源；颜色给色块，marker/线型给
  实际形状/线段预览。悬停轻提示、选中清晰高亮，编辑覆盖层不进入导出文件。
- 七曲线示例优先使用小尺寸仍清晰的实心形状（含五边形、五角星），不用细线加号或叉号；
  常用 marker 选择器直接展示七种形状；旧项目中的加号和叉号继续读取与导出，避免破坏兼容性。
  七种闭合形状都提供实心、空心轮廓两款，在选择器中按形状成行、两款并列；
  空心款的图内 marker 与图例样本保持一致，旧项目缺少填充字段时仍按实心读取。
- 七条示例曲线默认不显示会遮挡数据的图例或旧标注；导入文件后以文件名建立初始图例，用户
  双击画布图例打开编辑窗，不保留顶部“编辑图例”重复入口。“添加文字”可反复创建图内文字，创建后立即编辑，
  支持拖动定位、双击重开、隐藏和删除；不要求先打开侧栏。
- 最终按以上条目逐项检查功能、视觉、旧项目兼容与导出；macOS 实测，Windows
  最大化/全屏行为在 Windows 环境复核。

图例布局补充（2026-09-24）：小窗提供“自动 / 图内 / 图上 / 图右”，不提供图下。
自动先检查图内与曲线、标注的重叠；不合适时比较图上、图右增加的画布面积。
图上条目按实际标签宽度自动分列，五条与七条使用同一规则。主图基准尺寸默认
85 × 65 mm；图外图例不压缩主图及轴区，而是在图上或右侧增加紧凑的专用画布带。
图例编辑窗可指定行数或列数，另一维根据可见条目数自动计算，避免空行/空列；
自动排列仍为默认值。拖动图例本身用于移动位置，不将普通移动手势误作调整行列。
所有图例模式都显示实际位置，统一以最终导出画布左上角为 (0, 0)，单位 mm，
坐标指图例选中框左上角；修改坐标后固定当前位置。自动模式修改坐标时转为当前
图内/图上/图右模式；图上或图右修改坐标仍保持其图外模式。切换位置模式时重置
图外手动位置，重新按该模式排布。旧项目不含图外手动位置标志时维持自动排布。
主图尺寸后续变化时，图右手动坐标至少保持距轴区 6 pt，不让旧坐标压到数据区。
若右侧图例高度超过主图基准画布，则仅向下增加所需的导出画布空间，主图和 X 轴
标题保持原位；图上图例过宽时同理仅向右增加所需空间。
图内图例若因手动行列设置超出原画布边界，也只在越界方向增加所需空间，不改变
轴区宽高。
最终 PDF/PNG 的物理尺寸随图例带增大，并在编辑窗和导出窗明确显示；用户仍可手动
调节主图基准尺寸。
出版检查的 PNG 像素数按扩展后的最终画布计算；超出光栅安全上限时返回可读错误，
不能因分配失败而退出应用。统一审计覆盖工作区及独立原型的测试。
旧项目缺少位置字段时保留原图内坐标；图例可在图内、图上和图右区域之间拖动，图外放置不会挤压主图。
项目格式升为 schema 4，读取 schema 3 时自动迁移并保留原有图例坐标。
后续数据管理维护将格式升为 schema 5：嵌入数据可保留原始文件来源，用于项目重开后按文件移除；
schema 4 项目自动迁移，旧项目没有来源信息时仍可按数据区删除或清空全部数据。
图例移出轴区时，画布预览和 PDF/PNG 都必须保留彩色线段与 marker；预览裁剪结束后恢复
原画布裁剪区域，不能只显示图例文字。

多子图布局约束（2026-09-24）：图外图例不得仅压缩所属子图的一个方向，以免
轴框长宽比变化或多子图轴框大小不一致。当前单轴实现遵循“主图不变、扩展最终
画布”的规则；将来多子图应使用整张图共享的图例带，所有子图单元保持一致大小。
多子图共享图例尚未实现，不能视为已完成。
