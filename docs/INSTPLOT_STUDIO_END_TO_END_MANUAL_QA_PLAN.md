# InstPlot Studio 全功能端到端人工测试计划

> 状态：READY FOR INDEPENDENT EXECUTION
> 版本：1.0
> 日期：2026-09-24
> 对象：本机已安装的 `$HOME/Applications/InstPlot Studio.app`
> 范围：Studio 单 axes V1；不测试 Lite 联调、安装器发布、公证、Windows 或多 axes

## 1. 测试目标

本计划从真实用户视角验证完整工作流，而不是确认某段代码或单元测试存在。核心目标是证明：

1. 用户能从启动应用开始，完成“导入数据 → 选择 X/Y → 编辑图形 → 保存项目 → 重开 →
   出版规范检查 → 导出 PDF/PNG”的闭环；
2. 所有画布对象都能通过直观入口选中、双击编辑或按住拖动，修改即时反馈且不丢失；
3. 普通窗口、macOS 最大化（Zoom）和原生全屏三种状态下，主窗口、独立小窗与全屏回退均可用；
4. 界面保持紧凑、中文、无旧编辑器或冗余入口，不出现裁切、重叠、无法找回的窗口；
5. 保存重开和最终 PDF/PNG 与画布语义一致，字体、数学符号、刻度、图例和物理尺寸不回退；
6. 任何崩溃、数据错绑、静默失败、不可逆丢失或预览/导出明显不一致都必须被记录为失败。

## 2. 执行原则

- 由未参与本轮实现的独立 agent 操作已安装应用，不修改源码，不用代码阅读代替界面结果。
- 每个用例记录 `PASS / FAIL / BLOCKED / NOT RUN`；只有实际看到预期结果才可写 PASS。
- FAIL 必须记录：用例 ID、窗口状态、精确步骤、实际结果、预期结果、是否稳定复现、截图。
- 测试生成物统一放入 `/tmp/instplot-studio-e2e-qa/`，不得覆盖用户原文件。
- 用户已说明当前没有需要保存的内容；测试中应用卡死或需要安装版本重启时，可直接退出后重开。
- 一项失败不应停止全部测试；记录后继续不依赖该功能的用例。崩溃后从最近保存的测试项目恢复。
- 不把单元测试、Clippy 或审计脚本通过当作人工用例通过；它们只作为最后的补充证据。

## 4. 通过门槛

- P0：崩溃、无法启动、数据错绑/丢失、保存项目损坏、导出失败或导出内容错误。任何 P0 均不通过。
- P1：核心操作无入口、窗口在某种模式下不可见/不可找回、选择 X/Y 不更新、图例/文字不能编辑或拖动。任何未解释的 P1 均不通过。
- P2：对齐、间距、裁切、反馈延迟、文字不统一等界面问题。允许形成明确修复清单，但不能写“全部验收通过”。
- 全部 P0/P1 用例通过，P2 已逐项记录，才能给出“功能闭环通过”。

## 5. 执行顺序与用例

### A. 安装身份、启动与示例图

**A01 启动与唯一版本（N）**

1. 从 Spotlight 搜索并启动 `InstPlot Studio`。
2. 确认只出现一个结果，应用图标正确。
3. 核对底部显示产品名、版本和构建号。
4. 确认启动后只有一个主窗口，没有崩溃报告或重复进程窗口。

预期：显示七条曲线的示例图；菜单为中文；画布占主要区域；底部构建号与安装版本一致。

**A02 示例图视觉基线（N/M/F）**

依次切换 N、M、F，检查曲线颜色、线型、marker、四边 inward ticks、边界副刻度、数学负号、
X/Y label、图例和画布比例。每次切换后等待重绘并截图。

预期：内容不裁切、不重叠，85 × 65 mm 图形比例不因窗口模式改变；退出全屏后状态保持。

### B. 数据导入与文件栏

**B01 首次真实导入替换示例（N）**

导入 `E-dsk_1_5V.csv`。

预期：示例曲线自动清除；真实曲线立即出现；文件名成为初始 legend；X/Y label 从列名合理生成；
左栏只出现文件卡片、X/Y 下拉和直接 `×`，没有搜索框、原始数据按钮、省略号或“选择 XY 列”标题。

**B02 四文件连续导入（N）**

依次导入其余三个 E-dsk CSV。

预期：四条曲线自动出现并使用四种不同颜色；四个文件卡片清楚分隔；文件名截断不挤走 `×`；
图例有四项且顺序与导入顺序一致。

**B03 X/Y 列切换（N）**

逐个展开至少两个文件的 X、Y 下拉，各改变一次合法列组合，再恢复。

预期：每次选择后画布立即更新，不回到主页面，不串改其他文件，不出现空白图或错误轴标签。

**B04 特殊数据（N）**

分别新建项目后导入 numeric headers、missing values、multi-source、source-fit 夹具。

预期：数字列名可选；缺失值只形成断点而不导致整条曲线消失；多 source 全部出现；source/fit
关系、颜色和 legend 可辨认。错误必须明确显示，不能静默无反应。

**B05 支持格式（N）**

用真实文件或临时等价夹具逐项导入 CSV、TSV、TXT、DAT、XLSX、XLS。

预期：文件选择器允许选择；有效文件自动成图。若无可用 XLS/XLSX 人工夹具，标记 BLOCKED，
不得用自动测试冒充人工 PASS，并在结果中单独引用相应自动测试证据。

**B06 左栏伸缩、长名与滚动（N/M）**

拖动左栏到最窄、默认、最宽；导入/构造长文件名；滚动四个文件卡片。

预期：宽度有合理上下限；绘图区仍占主体；X/Y 控件和删除按钮不被挤出；悬停可获完整路径；
没有横向无限扩张。

**B07 单文件删除、清空全部、撤销/重做（N）**

删除中间一个文件并确认；撤销、重做；执行清空全部并确认；再次撤销。

预期：仅相关曲线和 legend 项消失；无悬空条目；撤销/重做准确恢复同一颜色、绑定与顺序。

### C. 坐标轴、刻度、标签与画布

**C01 坐标范围和自动范围（N）**

双击 axes/刻度区域，修改 X/Y min、max，再执行自动范围。

预期：合法值即时更新；非法范围不给错误图；自动范围完整包含数据。

**C02 主副刻度与 scale（N）**

检查/修改线性轴、固定主刻度间隔、副刻度自动/固定间隔、格式和精度；用正值数据切换 log10。

预期：四条 spine 均有 inward ticks；首尾边界区间存在副刻度；负值使用数学负号；log 坐标正确。

**C03 X/Y label 编辑一致性（N/M/F）**

分别双击 X、Y label，在三种窗口状态编辑普通文字、长标题与单位。

预期：三种状态进入同一简洁编辑器；窗口或全屏回退始终可见；X/Y label 不出现旧标签、语义片段、
添加片段等旧界面；长输入可查看和编辑。

**C04 科学标签输入（N）**

依次验证：普通区正体 Latin/Greek/上下标、`$...$` 内斜体变量、组合上下标 `R_x^y` 与 `$R_x^y$`、
`<=`/`>=`、`\sigma`、`$\sigma$`、`\sum`、`µ`、`\*`、
手动 `$...$` 兼容输入以及自动闭合 `() [] {} （）【】`。

预期：工具按钮同高同基线；只有必要内容进入数学模式；裸 `*` 有清楚提示，`\*` 正常显示；预览、
保存重开和 PDF 字形一致；不出现缺字方框。

**C05 画布缩放、平移与坐标状态（N/M/F）**

使用鼠标滚轮和触控板常规缩放手势；在 axes 四角和中心移动指针；缩放后再次取点。

预期：缩放以指针为中心且不改变物理图尺寸；触控板滚动不被误判；底部坐标只在 axes 内显示，
线性/log 反算正确；三种窗口状态均不丢失画布。

### D. 曲线、marker、颜色和对象选择

**D01 对象选择反馈（N）**

单击每类对象：曲线、marker、axes、X/Y label、legend、annotation。

预期：选中对象有清楚但轻量的边框/高亮；边框紧贴可见内容，不改变正式布局或导出。

**D02 线条实时编辑（N/M/F）**

双击曲线，依次修改角色、颜色、实线/虚线/点线/点划线。

预期：颜色名称不带 `object-`；选择后实时刷新；三种窗口状态都能完成并找回编辑器。

**D03 marker 完整性（N）**

逐项检查 circle、square、triangle up/down、diamond、pentagon、star 的实心/空心样式。

预期：菜单直接绘制形状预览；实心/空心清楚；没有不明显的 `+`/`×` 作为主要选择；保存重开一致。

**D04 多窗口共存（N/M）**

同时打开曲线、axes、label、legend/annotation 编辑窗口，再单击主图。

预期：已打开窗口不会因点击主图自动关闭；窗口可独立移动、关闭、重新打开；没有窗口永久藏到主窗后。

### E. 图例

**E01 图例入口和编辑（N）**

双击画布图例。

预期：无需顶部“编辑图例”按钮；编辑器显示可见性、位置/坐标、行列和条目顺序；无无意义大块空白。

**E02 图例内容、顺序与行列（N）**

重命名一个条目，数字修改顺序，隐藏/恢复条目，设置 1×N、N×1 和多行多列。

预期：画布即时更新；无失效上下箭头；条目不重叠；对象框随内容紧密变化。

**E03 图例拖动跨区域（N/M/F）**

按住图例依次拖到图内、图上、图右，再从图外连续拖回图内；缓慢和快速各做一次。

预期：拖动丝滑，不需“用力”；跨边界不跳位；松手后位置稳定；命令窗坐标随位置准确更新。

**E04 图外图例与画布（N）**

分别使用 4、5、7 个条目测试图上/图右，多种行列布局；将图例拖远再松手。

预期：85 × 65 mm 主图不缩放、不拉伸；仅增加紧凑图例区域；图例自动收拢到主图附近；最终导出
不因远距离拖动留下大片空白。若出现跳位或过大空白，按 P1 记录。

### F. 标注文字

**F01 添加、编辑与拖动（N/M/F）**

顶部“添加文字”创建短、长、数学标注；双击编辑；按住拖动到 axes 内多个位置。

预期：创建后入口明确；文字和选择框贴合；拖动实时、无跳位；三种窗口状态编辑器均可用。

**F02 清空即删除与撤销（N）**

清空已有标注输入框并关闭窗口，然后撤销、重做。

预期：清空时提示关闭后删除；没有单独“删除”按钮；关闭后标注删除；撤销/重做为一个完整动作。

### G. 图形尺寸、出版检查与导出

**G01 图形尺寸（N）**

打开尺寸编辑，将默认 85 × 65 mm 改为另一合法值后恢复。

预期：界面只显示画布尺寸；默认没有 89 × 65；宽高可编辑；label/ticks 与画布边缘规则稳定。

**G02 Publication Check（N/M/F）**

在三种窗口状态打开检查；测试全通过、warning 和 error 情形。

预期：N/M 为可移动非阻塞独立窗口，不挤压绘图区；F 使用可见且可操作的全屏回退；只列错误和
警告；全通过仅显示“未发现出版规范问题”；关闭后选择状态不变。

**G03 PDF 导出（N）**

导出包含数学标签、四条曲线、marker、图外 legend、annotation 的 PDF。

预期：文件生成；主图比例与位置正确；`≤/≥` 等符号与预览一致；字体嵌入；数学负号正确；无选择框。

**G04 PNG 导出（N）**

分别导出常规背景和透明背景（若界面提供），核对 DPI/像素信息。

预期：文件可打开、尺寸正确、内容完整；透明与白底结果不同；无多余大空白。

**G05 导出阻断（N）**

制造明确 publication error 后尝试导出，再修复后导出。

预期：错误状态给出可理解原因并阻止不合格导出；修复后正常完成；不崩溃、不生成半文件。

### H. 项目生命周期与恢复

**H01 保存、另存为、重开（N）**

保存当前完整项目到临时目录，关闭并重开；再另存为新名称。

预期：曲线绑定、颜色、marker、axes、标签、图例位置/行列、annotation、图形尺寸全部一致。

**H02 未保存变更（N）**

修改后执行新建、打开项目和退出，分别测试取消与放弃更改。

预期：提示明确；取消保持当前状态；放弃后执行目标动作；不出现重复提示或崩溃。

**H03 旧项目迁移（N）**

打开 `project-v0.instplot`，查看警告并另存为当前格式，再重开。

预期：旧项目能迁移或给出明确错误；不会覆盖原夹具；另存的新项目可正常打开。

**H04 撤销/重做跨功能（N）**

连续执行颜色、X/Y 范围、label、图例位置、annotation、删文件，再逐步撤销并重做。

预期：顺序严格、没有跳步；保存点与标题 `*` 状态正确；不可用时按钮禁用。

### I. 窗口模式专项矩阵

以下操作必须在 `N / M / F` 三种状态各执行一次，不能只检查截图：

1. 导入一个数据文件；
2. 打开 X label 编辑器并输入文字；
3. 同时打开曲线与 legend 编辑器；
4. 拖动 legend；
5. 添加并拖动 annotation；
6. 打开 Publication Check；
7. 使用滚轮/触控板缩放；
8. 保存项目并打开导出入口；
9. 在小窗打开时从 N→M→F→N 循环一次。

共同预期：窗口不消失、不被主窗口永久遮挡、不跑到屏幕外；控件不裁切；操作不中断；回到 N 后
位置和内容保持。F 下若设计为嵌入式回退，必须功能等价且退出全屏后恢复正常独立窗口行为。

### J. 稳定性与关闭

**J01 连续操作稳定性**

连续执行至少 20 次对象选择/双击编辑、10 次缩放、5 次窗口模式切换和 3 次导入/删除循环。

预期：无崩溃、卡死、显著内存增长、残影、输入失效或重复窗口。

**J02 关闭与重启**

在无未保存内容和有未保存内容两种状态退出并重启。

预期：无内容时干净退出；有内容时遵循提示；重启只有一个窗口，不出现“应用程序不能打开”或
系统崩溃报告。
