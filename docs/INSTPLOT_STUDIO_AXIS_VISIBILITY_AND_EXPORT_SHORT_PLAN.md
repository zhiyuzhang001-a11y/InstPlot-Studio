# InstPlot Studio 坐标轴显示与导出放行短修改清单

> 状态：`COMPLETED`
> 日期：2026-09-28
> 范围：只调整“坐标轴显示”窗口与导出确认逻辑，不改变绘图、数据、坐标映射或文件格式。

## 1. 坐标轴显示窗口

- [x] 保留“双击主图空白区域 → 打开或置顶坐标轴显示窗口”。
- [x] 不恢复原来的“双击适合窗口”行为。
- [x] 删除“更多设置”按钮及其打开第二个轴设置窗口的流程。
- [x] 将“更多设置”当前包含的范围、主刻度、副刻度和双轴 spine 颜色直接合并到同一个窗口。
- [x] 轴标签文字仍通过双击实际 X/Y label 编辑，不在此窗口重复放置完整文字编辑器。
- [x] 默认窗口约 `460 × 480`，最小尺寸约 `380 × 300`，允许自由调整大小。
- [x] 内容外层使用统一纵向滚动区；高度不足时自然出现滚动条，不能再出现内容被截断且无法滚动。
- [x] 顶部紧凑选择 X1、Y1，以及当前模式下存在的 X2 或 Y2。
- [x] 显示开关采用两行两列：轴线、刻度线、刻度数字、轴标签。
- [x] 自动范围、最小值、最大值尽量同排；主刻度模式与间隔同排；副刻度模式与间隔同排。
- [x] 只有双 X/双 Y模式显示对应 spine 颜色。
- [x] 普通窗口、最大化和全屏使用同一内容结构；重复双击只置顶，不重复创建窗口。

## 2. 导出确认

- [x] Publication Check 的错误和警告继续显示，但不再禁用导出按钮。
- [x] 没有规范错误时显示“立即导出”；存在规范错误时显示“仍然导出”。
- [x] 将“请先修复 Publication Check 错误”改成“存在出版规范问题，检查后仍可导出”一类提示。
- [x] 警告不增加额外阻断步骤。
- [x] 空 X2/Y2 时继续醒目提示，并同时提供“改为单轴并导出”和“仍然导出”。
- [x] 切回单轴后占位标签和额外 gutter 同帧消失，再执行导出。
- [x] 真正的布局失败、无效输出尺寸、渲染失败或文件写入失败仍由导出事务阻止并显示明确原因。
- [x] 隐藏刻度线、刻度数字、轴标签，甚至图中没有文字，都不得仅因出版规范规则而失去导出入口。

## 3. 验收

- [x] 单轴、双 X、双 Y分别检查窗口内容、轴选择和滚动。
- [x] 小窗口尺寸下滚动可达全部控件；扩大窗口后不出现多余嵌套滚动区。
- [x] 修改范围、主/副刻度、显示开关和 spine 颜色后立即更新主图，并保持 Undo/Redo。
- [x] 隐藏刻度线和刻度数字后，PDF、SVG、PNG 均可导出。
- [x] 构造至少一个 Publication Error，确认“仍然导出”可生成文件，同时错误摘要仍然可见。
- [x] 空副轴的两个导出选择均可执行，且“改为单轴并导出”正确恢复单轴布局。
- [x] 运行格式检查、相关定向测试、完整 workspace 测试及严格 Clippy。
- [x] 独立 agent 按本清单进行功能验收后，才替换 Spotlight 应用；本轮不提交 GitHub。
