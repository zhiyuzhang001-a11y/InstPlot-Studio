## 1. 目标

本阶段在不回退现有单轴、双轴、文字标注、图例和导出行为的前提下完成三项能力：

1. 仅在双 X 或双 Y 模式下允许分别设置主、副轴对应 spine 的颜色；
2. 扩展文字连接线，并增加适合科研图中区间、方向和变化量表达的独立测量箭头；
3. 为已经存在的水平/垂直参考线对象提供直接、连续、可精确编辑的新增与拖拽入口。

目标示例包括：在同一主图中添加多条竖直虚线，在相邻参考线之间添加水平双向箭头，
并使用数学标签标注 `Δt = 255 s`、`Δt = 600 s`。

## 2. 不可变规则

### 2.1 单轴轴墨色与双轴 Spine 颜色

- 单轴模式不显示颜色设置；spine、主/副刻度线、刻度数字和轴标签等基本轴信息统一使用纯黑 `object-black`。
- 当前布局使用的深灰轴墨色 `[45, 50, 55]` 将有意调整为纯黑；这是经确认的出版外观修订，不作为回归处理。
- 只有启用双 Y 或双 X 开关后，才显示对应主轴和副轴的 spine 颜色控件。
- 双 Y 模式只开放 Y1 左 spine 与 Y2 右 spine 的颜色；上下 spine 保持黑色。
- 双 X 模式只开放 X1 下 spine 与 X2 上 spine 的颜色；左右 spine 保持黑色。
- 主、副 spine 默认均为黑色，不因启用双轴自动变成曲线颜色。
- 颜色选择器复用曲线当前使用的颜色选择器、颜色名称和活动配色方案，不建立第二套颜色注册表。
- 双轴自定义色只改变对应 spine；刻度线、刻度数字和轴标签仍保持黑色。
- 关闭双轴时，双轴颜色作为休眠设置保留，但单轴预览和导出必须强制使用黑色；重新启用同一种双轴模式后恢复此前颜色。
- 在双 Y 与双 X 之间切换时，两套颜色状态分别保存，不互相覆盖。
- 切换配色方案时，`object-black` 和仍存在的语义色原样保留；旧系列色按色板序号映射到新色板，无法映射则回退 `object-black`。X1/X2 与 Y1/Y2 分别迁移，不能串色。
- 预览、PDF、SVG、PNG 与项目重开必须使用同一颜色解析结果。

### 2.2 三种对象不得混用

本阶段明确区分：

- **文字连接线**：起点依附文字可见边界，终点指向一个数据坐标；用于解释某个点或区域。
- **测量箭头**：拥有两个独立端点，可无文字或关联一个标签；用于表达区间、方向、距离或变化量。
- **参考线**：横跨整个坐标轴区域的水平线或垂直线；用于标记阈值、事件位置或分界。

不得用隐藏文字模拟独立箭头，不得用普通数据曲线模拟参考线，也不得把参考线塞入文字连接线数组。

### 2.3 坐标与渲染规则

- 文字位置继续使用画布 point 坐标；文字连接线终点继续使用绑定轴的数据坐标。其水平、垂直和 45°只属于拖拽时的屏幕空间吸附，不作为范围变化后的永久视觉角度约束。
- 测量箭头两个端点均使用同一 `AxisBinding` 下的数据坐标，随坐标范围和画布尺寸正确重算。
- 测量箭头的水平约束表示两端数据 Y 相等，垂直约束表示两端数据 X 相等；首版不保存任意固定角度。
- 竖直参考线规范化为 `(selected X, Y1)`，水平参考线规范化为 `(X1, selected Y)`；切换方向或绑定轴时立即清理无关维度。
- 参考线的有效可见性和 autoscale 只由其方向相关轴决定，不能因无关维度休眠，也不能形成 X2/Y2 组合。
- 参考线位置使用相关轴的数据值并严格裁切在 axes bounds 内。
- 参考线和测量箭头均禁止成为图例条目，不改变逻辑数据系列身份，也不参与出版规范中的系列颜色、marker 或 line style 区分检查。
- 参考线默认不参与 autoscale；编辑器提供“纳入自动范围”选项，显式开启后才扩展对应轴范围。
- 参考线绘制在数据曲线后方；测量箭头和文字连接线绘制在数据曲线上方。
- 测量箭头线段与箭头头裁切在 axes 内；其标签可进入 figure 空白，但不能扩展导出边界，超出 figure 时产生布局警告。
- 直接拖拽参考线或箭头端点时限制在 axes 内；精确数值输入允许暂时位于范围外并给出提示，对象继续保存但不可见。
- 所有对象必须通过同一 Display List 进入预览和全部导出后端，不允许为 PDF、SVG 或 PNG 分别实现几何逻辑。

### 2.4 已提交状态与手势草稿

- Project Document 是所有已提交对象的唯一持久事实来源。
- AppState 可以保存一次创建或拖拽手势的临时 `ToolDraft`，但不得保存第二份已提交对象。
- Esc 丢弃草稿；鼠标释放后通过一个 `EditCommand` 原子提交，撤销时一次移除整个对象。
- modifier 状态随每个拖拽事件形成快照；不能在 controller 的另一帧读取不确定的全局 Shift 状态。

### 2.5 测量箭头标签所有权

- 测量箭头通过专属 `Option<label_id>` 引用 semantic registry；一个标签不得被多个对象共享。
- 清空标签只删除关联标签，不删除箭头；无标签箭头保持有效。
- 删除箭头必须清理其专属标签，不能留下 orphan；复制功能本轮不开放。
- label offset 使用 point 单位，默认位于线段中点上方，并作为箭头对象的一部分保存和撤销。

## 3. 交互设计

### 3.1 双轴 Spine 颜色入口

- 颜色控件放入已经启用的副轴设置窗口，不增加单独的全局颜色窗口。
- 双 Y 设置显示“左侧 Y1 spine”和“右侧 Y2 spine”；双 X 设置显示“下方 X1 spine”和“上方 X2 spine”。
- 每项使用与曲线一致的颜色色块和下拉选择，默认显示“黑色”。
- 修改后立即刷新预览；取消或关闭窗口不重置已提交选择。
- 双轴开关关闭时颜色控件立即消失，单轴画面立即恢复黑色。

### 3.2 文字连接线

保留当前“连接线与箭头”区域，并整理为紧凑的一行或确定性换行布局。每条连接线支持：

- 无箭头、末端箭头、起点箭头、双向箭头；
- 开放式箭头头和实心三角箭头头；
- 颜色、线宽、线型、箭头大小；
- 终点直接拖拽和 X/Y 精确输入；
- 拖拽时按住 Shift 临时吸附到水平、垂直或 45°；
- 释放后只保存合法的终点数据坐标，不承诺坐标范围、画布尺寸或文字边界变化后继续保持原视觉角度。

连接线起点仍由文字可见墨迹边界自动计算，避免线段穿过文字。若用户需要自由控制两个端点，使用测量箭头，不把文字连接线改成含糊的双用途对象。

### 3.3 独立测量箭头

顶部“添加”区域增加“测量箭头”入口。新对象具备：

- 两个可独立拖拽的端点；
- 拖动线身可整体平移；
- 无箭头、起点、终点、双向四种端点模式；
- 开放式与实心三角两种箭头头；
- 自由、水平和垂直三种约束；
- 自由拖拽时 Shift 吸附到 0°、45°、90°及其对称方向；
- 精确编辑起点和终点 X/Y；水平箭头可编辑 `ΔX`，垂直箭头可编辑 `ΔY`，自由箭头只读显示屏幕角度；
- 首版不提供通用长度输入和任意持久固定角度，因为不同单位、双轴和对数轴下没有统一物理意义；
- 测量箭头固定使用黑色 `object-black`，不提供颜色选择；默认 `0.9 pt`、实线和末端箭头；
- 使用同一个“测量箭头”入口，在创建前选择普通指示或水平双向测量预设，避免顶部出现两个重复按钮；
- 可选标签，默认位于线段中点上方，可继续拖动偏移；
- 标签复用现有数学输入、换行、字体、选择框和导出链路。

添加流程：选择工具后在主图按下并拖到终点，释放后完成；短距离单击不创建退化对象。Esc 取消，完成一个对象后默认返回选择工具，避免意外连续创建。

### 3.4 参考线

顶部“添加”区域增加“参考线”入口，提供“竖直参考线”和“水平参考线”两个明确选项：

- 选择方向后进入连续添加模式；
- 在主图中单击即按当前绑定轴的数据值添加一条参考线；
- 可连续单击添加多条，按 Esc、切换工具或再次点击已激活按钮退出；
- 双轴模式下，在工具条中先选择 X1/X2 或 Y1/Y2，默认主轴；不依据点击位置猜测绑定轴；
- 竖直模式只存选择的 X 轴并规范化为 `(selected X, Y1)`；水平模式只存选择的 Y 轴并规范化为 `(X1, selected Y)`；
- 竖直参考线只能左右拖动，水平参考线只能上下拖动；
- 拖动时显示当前精确数值，双击打开对象窗口；
- 对象窗口提供方向、值、相关轴、颜色、线型、线宽和“纳入自动范围”；
- 颜色选择复用曲线色板、颜色名称和 palette 迁移规则，默认黑色；
- 默认黑色、`0.9 pt`、虚线、不纳入自动范围；
- 删除、撤销、重做、保存重开和导出行为与其他正式对象一致；复制快捷功能本轮不实现。
- 参与 autoscale 的参考线拖拽期间冻结起始轴变换，只更新 runtime preview；释放时原子提交并重新 autoscale，避免范围与指针互相追赶。
- 对数轴拒绝非正参考值，不能留下半次编辑。

## 4. 数据模型与兼容性

### 4.1 项目模型

计划新增或扩展以下持久字段：

- `AxisAppearanceRecord`：双轴 spine 颜色标识；字段带安全默认值 `object-black`。增加 String 后该结构不再派生 `Copy`，调用点必须显式借用或 clone。
- `AnnotationConnectorRecord`：增加箭头头型；角度吸附属于手势状态，不增加持久方向约束。
- `ArtistProperties::MeasurementArrow`：两个数据端点、规范 AxisBinding、黑色 stroke、箭头端点模式、箭头头型、自由/水平/垂直约束、专属可选 label ID 和 point 单位标签偏移。
- `ArtistProperties::ReferenceLine`：增加 `include_in_autoscale`；新建参考线默认关闭，旧项目迁移时保留当前会影响范围的既有行为。

现有参考线的方向、值、绑定轴和 stroke 继续复用，不重新建立第二种参考线结构。

### 4.2 Schema

- 当前项目格式为 schema 8；新增测量箭头和持久样式后统一升级到 schema 9。
- 提供 8 → 9 迁移，不能要求用户手工重建已有项目。必须保留至少一份真实 schema 8 fixture，不能只修改当前 fixture 的版本数字。
- 迁移沿用当前 JSON 修补结构：各旧版本先执行已有修补，再统一调用 `upgrade_value_to_v9` 注入 schema 9 字段，最后只反序列化一次；本轮不顺手重构为完整逐级迁移管线。
- schema 0–7 也必须经过统一的 `upgrade_value_to_v9`；迁移 provenance 名称和诊断必须准确反映最终版本，不能继续声称只迁移到 schema 8。
- 所有旧轴显式注入黑色 spine；旧文字连接线显式注入开放式箭头头。
- 旧参考线迁移为 `include_in_autoscale = true`，避免悄悄改变已有项目的范围；新建参考线默认 `false`。该兼容策略必须用迁移测试固定，不能依靠 serde 隐式默认形成未记录行为。
- 旧参考线根据方向规范化 AxisBinding；若旧值含无关副轴，迁移后不得因此错误休眠或形成 X2/Y2。
- schema 9 必须通过 JSON round-trip、保存重开和非法字段校验。

### 4.3 双轴休眠

- 关闭副轴不删除其 spine 颜色、参考线、测量箭头或文字连接线绑定。
- 绑定休眠轴的参考线、测量箭头和连接线在该模式下不渲染、不命中、不导出；参考线只判断方向相关轴。
- 重新启用对应副轴后恢复其对象和样式。
- 禁止把休眠对象迁移到主轴，禁止改写其持久 `visible`。

## 6. 测试矩阵

### 6.1 Spine

- 单轴：无颜色控件；spine、刻度线、刻度数字和轴标签均为纯黑；旧项目打开后也采用该确认过的新轴墨色规范。
- 双 Y：左/右可独立着色；上下保持黑色。
- 双 X：下/上可独立着色；左右保持黑色。
- 关闭副轴：立即恢复全黑；重开副轴：恢复颜色。
- 双 Y ↔ 双 X：各自颜色不串联。
- 切换配色方案：spine 使用与曲线相同的合法颜色解析和迁移路径。

### 6.2 文字连接线与测量箭头

- 四种端点箭头模式和两种箭头头均可预览、保存和导出。
- 连接线起点不穿过文字，空文字关闭仍按现有规则删除标注。
- 测量箭头两个端点、线身、标签分别命中正确。
- 文字连接线 Shift 临时吸附稳定且不伪装成持久角度；测量箭头自由/水平/垂直约束稳定。
- 水平测量箭头的 `ΔX`、垂直测量箭头的 `ΔY` 可精确编辑；自由箭头角度只读，不出现含义不清的通用长度输入。
- 测量箭头始终为黑色且没有多余颜色控件。
- 线性、对数、反向范围和双轴绑定下不产生 NaN、越界或错误命中。
- 缩放、平移、改范围后数据坐标保持不变，水平/垂直约束不丢失。
- 创建草稿可被 Esc 原子取消；Shift 按下和松开的事件快照正确；提交后只存在一份 Project Document 状态。
- 删除箭头清理专属标签，清空标签不删除箭头，保存重开不产生 orphan label。

### 6.3 参考线

- 水平/垂直连续添加、Esc 退出、拖拽、双击编辑、删除和撤销均正常。
- 默认不改变 autoscale；显式开启后只扩展所绑定轴。
- X2 竖线和 Y2 横线按相关轴正确休眠与恢复；无关维度不会使参考线休眠，也不会形成 X2/Y2。
- 不进入图例，不触发系列颜色/marker/line style 区分警告。
- palette 切换后参考线颜色按系列序号映射或回退黑色，不留下无效 color ID。
- 100 条参考线下仍能完成选择、拖拽和导出，不出现明显冻结或错误命中。
- 参与 autoscale 的参考线拖拽不抖动；对数轴非正值被原子拒绝。

### 6.4 回归

- 图例仍遵循：纯 marker 只画 marker，纯 line 只画 line，点线图同时显示二者。
- 误差棒自动范围、双轴独立范围和边界刻度不回退。
- 标注、图例和新对象的小窗口在普通、最大化、全屏下可移动、可置顶、可找回。
- 保存项目不改写外部数据；导入与录入数据行为不受影响。
- Spotlight 始终只有一个应用副本，但开发期间不自动覆盖安装版本。

## 7. 主要代码责任

- `apps/instplot-studio/src/project.rs`、`project/migration.rs`、`project/validation.rs`：schema、持久模型、迁移和校验。
- `apps/instplot-studio/src/document.rs`、`document/autoscale.rs`、`document/objects.rs`、`document/datasets.rs`：正式文档转换、对象操作、系列排除和范围策略。
- `crates/instplot-layout/src/model.rs`、`layout.rs`：spine、连接线、测量箭头、参考线几何与命中。
- `apps/instplot-studio/src/app_controller.rs`、`app_ui.rs`、`app_state.rs`、`canvas_support.rs`、`editor_support.rs`、`editing.rs`、`app_transactions.rs`：工具草稿、窗口、拖拽、编辑器和原子事务。
- `apps/instplot-studio/src/palette.rs`：复用颜色注册表，不建立新的颜色事实来源。
- `apps/instplot-studio/src/publication.rs`、`semantic.rs`：把参考线和测量箭头排除于数据系列编码检查，并保持正确对象语义。
- `apps/instplot-studio/src/ui_text.rs`：中英文界面文字。
- 各层现有测试文件及导出合同测试：模型、迁移、布局、交互、窗口和多后端回归。

## 8. 明确非目标

本阶段不实现：

- 四轴同时启用；
- 任意曲线或贝塞尔绘图工具；
- reference band、填充区间或复杂括号标注；
- 自动从数据峰值、突变点或文件语义猜测参考线位置；
- 将 spine 颜色自动绑定到某条曲线；
- 自动联动 spine、tick、tick label 和 axis label 的颜色；
- 测量箭头的颜色选择；
- 任意持久固定角度和跨单位的通用长度输入；
- 参考线或测量箭头的复制快捷功能；
- 大量装饰性箭头头、三维箭头或路径文字；
- release、发布标签或 Windows/Linux 构建；GitHub 仅上传本阶段源码、文档与测试。

## 9. 最终完成标准

只有同时满足以下条件才能把本计划标记为 `DONE`：

1. 单轴的 spine、刻度线、刻度数字和轴标签始终为纯黑，且界面没有多余颜色控件；
2. 双 X/双 Y 可以独立设置所需的两条 spine，关闭与恢复行为正确；
3. 参考线能够通过顶部入口连续、精确地添加和编辑；
4. 文字连接线与独立测量箭头职责清晰；临时角度吸附、双向箭头、`ΔX`/`ΔY` 和自由/水平/垂直操作顺畅；
5. 示例图中的竖直参考线、水平双向箭头和数学标签可在不伪造数据曲线的情况下完成；
6. 项目迁移、撤销重做、双轴休眠、保存重开和所有导出格式一致；
7. 自动测试、真实窗口操作和独立 agent 验收全部通过；
8. 唯一 Spotlight 应用验证通过，源码分支上传 GitHub；release 和 Windows/Linux 交付留待后续单独授权。
