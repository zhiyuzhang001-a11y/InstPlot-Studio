# InstPlot Studio Phase 7：UI 设计系统与窗口策略

状态：已完成
完成日期：2026-09-25

## 统一设计系统

`crates/instplot-ui` 现在提供可复用的界面层能力：

- `InterfaceMetrics`：字体、控件高度、水平与垂直间距的单一规范；
- 亮色/暗色 surface、card、side panel、file card；
- 对齐一致的关闭按钮、标签格式按钮和数学符号按钮；
- Studio 二进制只保留产品组合，不再复制主题实现。

## 统一工具窗口策略

新增 `ToolWindowPolicy` 与 `ToolWindowSpec`：

- 普通窗口模式：工具窗口是可移动、可缩放的非模态独立原生窗口；点击主图时保持打开，但不使用
  系统级“永远置顶”，切换到其他应用时不得继续覆盖其他应用；
- macOS 全屏或 Windows 最大化：工具窗口嵌入当前主窗口，避免原生子窗口丢失或跑到不可见空间；
- 两种模式共享默认尺寸、最小尺寸、关闭行为和内容组件；
- 录入数据、配色方案、出版规范检查、对象编辑器已接入同一策略；
- 同一入口首次触发时打开窗口；窗口已存在时再次触发只负责恢复、前置并聚焦，绝不切换关闭，
  也不得重置尚未提交的编辑内容；关闭只由窗口关闭按钮或明确的取消操作完成；
- 主图对象再次双击时，已有的对应编辑器前置而不重复创建；顶栏工具命令遵守相同行为；
- 文件导入、打开、保存和导出继续使用侧栏或系统文件选择器，不为文件本身创建常驻工具窗口；
- 点击主画布不会自动关闭已打开的对象编辑器，多个对象编辑器仍可并存。

## 用户文字

顶栏和录入数据窗口标题统一通过 `UiLanguage` 获取，避免同一命令在不同位置出现不同文字。领域诊断继续保持结构化信息，不进入通用组件层。

## 回归覆盖

- 设计度量测试确保同类控件使用统一高度和间距；
- 窗口策略测试覆盖普通、全屏和最大化三种状态；
- 既有按钮居中、侧栏布局、窗口存活、拖拽、触控板与编辑器测试全部保留。
