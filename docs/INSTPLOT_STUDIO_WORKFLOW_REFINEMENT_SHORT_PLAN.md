# InstPlot Studio 数据工作流与界面收尾短计划

> 状态：DONE（macOS；Windows 最大化/全屏实机复核按计划延期）
> 阶段代号：B5R（B5Q 画布优先框架之后、Lite 最终联调与 B6 发布准备之前）
> 制定日期：2026-09-24
> 上位计划：[`SCIPLOT_EXECUTION_PLAN.md`](SCIPLOT_EXECUTION_PLAN.md)
> 范围：Studio 单 axes V1 的多文件导入、界面一致性和最终人工验收；不连接 Lite、不发布

## 1. 阶段目标

B5R 不重新设计已经完成的 Figure Document、Display List、字体、布局或导出链路。它只处理
真实多文件使用后暴露出的产品收尾问题：让“导入文件 → 选择 X/Y → 自动画图 → 直接编辑 →
检查并导出”保持简单、紧凑、可预测，并防止已经完成的画布优先交互再次回退。

本阶段将“代码已存在”“自动测试通过”和“用户在已安装应用中确认”分开记录。只有对应验收
完成后，条目才可标记为 DONE。

## 2. 已完成基线（不得回退）

以下能力已经实现，B5R 只做回归验证，不重新设计：

- 画布是主界面核心，两侧区域默认按需出现；视图缩放不改变物理图尺寸；
- 支持 TXT/CSV/DAT/TSV/XLS/XLSX 数据路径、项目保存重开和 PDF/PNG 导出；
- 导入数据后建立正式 data source、series 和列绑定，不把 UI 状态作为第二事实来源；
- 每个文件已有内联 X/Y 下拉入口，冗余的“选择 X/Y 列”标题已移除；
- 文件条目使用直接的 `×` 删除入口，并已有清除全部数据的受控操作；
- 顶部“编辑图例”入口已移除；图例由导入文件名初始化，并从画布对象进入编辑；
- 旧的“旧标签 / 语义标签 / 语义片段 / 添加片段”回退编辑器已从当前标签流程移除；
- X/Y label、legend 条目和 annotation 使用同一套简洁标签输入，导入轴标签使用普通文本节点；
- 多个对象编辑窗口可共存，点击主图不应自动关闭窗口；全屏时有嵌入回退；
- 图例与 annotation 可拖动，图外图例扩展最终画布而不压缩 85 mm × 65 mm 主图；
- 四边 inward tick、边界区间 minor tick、数学负号、出版字体和预览/导出同源链路已经建立；
- Publication Check 的完整 finding 仍保留在内部模型中，便于自动审计和开发诊断；
- macOS 应用始终替换同一个安装位置，Spotlight 不创建多个副本。

## 3. 已实现但必须重新验收

这些项目已有实现，但最近的真实操作曾出现问题，不能仅凭代码状态判定完成：

- 导入文件后自动出现曲线；切换任一文件的 X/Y 列后，画布立即更新且不会返回主页面；
- 同名、长文件名和多个文件的绑定互不串联，单独删除文件不会留下悬空 series；
- 文件名正确成为初始 legend label，双击图例能进入当前简洁编辑器；
- X/Y label 编辑器在示例文档和真实导入文档中完全一致，不出现旧版本窗口；
- 独立编辑窗口在普通、最大化和全屏状态下可见、可移动、可找回；
- 颜色、marker、线型修改实时刷新预览，并保持保存重开和导出一致；
- 已安装应用与当前源码构建一致，版本或构建标识足以识别本次修订。

## 4. 本阶段剩余修改目标

### R0：多文件导入与左侧文件栏

- 新导入的独立文件依次使用不同的冻结 publication palette 颜色；同一 source/fit family
  仍共享颜色。至少四个文件同时导入时不得全部为蓝色；超过调色板数量时才允许确定性循环。
- 每个文件使用紧凑背景卡片或清晰分隔线，卡片内只显示文件名、删除入口和一组 X/Y 下拉框。
- 删除“数据文件”下方的文件搜索框及其按文件数量自动出现的分支。V1 直接通过紧凑文件卡片
  浏览全部已导入文件，不为少量文件增加搜索状态、占位文字或额外纵向空间。
- 文件名过长时截断，悬停显示完整路径；不得依文件名无限扩张侧栏。
- “数据文件”标题与右侧清空 `×` 使用同一行高、中心基线和合理间距；`×` 的字形必须在
  按钮方框内水平、垂直居中，不能因按钮内边距或字体基线显得偏上、偏下。
- 左侧栏可自由拖动；默认宽度比当前稍宽，同时保留合理最小/最大宽度，避免长期侵占绘图区。
- 左侧栏只承担文件和文件相关操作；其他编辑能力留在顶部菜单或画布对象窗口。

完成条件：用四个真实或等价夹具文件完成一次导入、换列、删单个、清空全部和重新导入；
四个系列颜色不同，所有曲线与绑定即时正确；无论导入多少个 V1 文件，左栏都不出现搜索框。

### R1：标签工具与通用排版一致性

- “斜体 / 下标 / 上标 / 正体”使用相同尺寸、字体行高和视觉基线；按钮文字水平、垂直居中。
- “数学符号与希腊变量 / 输入帮助”与第一排采用同一居中规则和一致的行间距，不再一排居中、
  一排靠左。
- 对全部对象小窗进行排版巡检：同一类别且宽度允许的控件优先放在同一行，只有空间不足或
  语义层级确实不同才换行；不得习惯性向下堆叠，留下大块无意义横向空白。
- 同行控件使用统一高度、基线、间距和列宽规则；窗口变窄时允许确定性换行，不能裁切文字或
  让控件互相覆盖。
- 检查所有对象小窗中相同类型的按钮、下拉框和输入行，修正文字贴边、按钮过矮、列宽失衡、
  无意义右侧空白和不必要的窗口高度。主刻度模式与主刻度间隔、副刻度模式与副刻度间隔等
  同类设置应优先同行排列。
- 输入帮助明确说明显示星号应写成 `\*`；解析、预览、PDF/PNG 和项目往返均验证该写法。
- “添加文字”窗口移除单独的“删除”按钮。编辑已有 annotation 时允许输入框暂时为空，并明确
  提示“关闭窗口后将删除此标注”；用户关闭窗口时才提交删除，并保持为一次可撤销编辑。
  继续输入内容则实时恢复/更新标注。不得用通用的“标签不能为空”错误阻止这一流程，也不得
  影响 legend 或 axis label 的非空校验规则。

完成条件：标签窗口两排工具在 macOS 实际渲染中对齐；`\*`、上下标、斜体、Greek 和关系符号
均能预览、保存和导出；清空 annotation 后关闭窗口能删除且可撤销；所有小窗完成一次同行布局、
窄窗口换行、基线与空白空间巡检。

### R2：对象边界与紧凑图外图例

- annotation 和 legend 的选择框、拖拽框、命中框及导出 bounds 必须以实际可见内容的墨迹范围
  为基础，只增加统一的小型交互安全边距；不能沿用明显过大的估算框。
- legend bounds 必须紧密包含实际可见的线段、marker 和文字。图例位于图上或图右时，专用画布带
  及最终导出画布按紧密 bounds 加规定间距计算，使图例能够靠近主图而不重叠。
- annotation 清空、legend 条目显隐、行列数变化及字号默认变化后必须重新计算 bounds，不能保留
  旧内容留下的空白区域。
- 选择高亮可以在紧密内容框外增加轻量视觉轮廓，但该 overlay 不得改变正式布局或进入导出。

完成条件：使用短/长 annotation、单列/多列 legend、图内/图上/图右位置逐项比较选择框和实际
墨迹；图外图例与主图间只保留规定间距，PDF/PNG 周围没有由虚大对象框造成的额外空白。

### R3：Publication Check 产品窗口

- Publication Check 改为可移动、非阻塞的普通独立窗口；不得作为右侧面板挤压绘图区。
- 产品窗口只显示 error 和 warning；information/pass 继续保留给内部审计，但不逐项展示。
- 无 error/warning 时只显示“未发现出版规范问题”。
- finding 若能关联对象，仍可从窗口定位对应对象；关闭检查窗不得改变图形或选择状态。

完成条件：分别使用全通过、仅 warning 和含 error 的三个夹具确认窗口内容；窗口打开前后绘图区
尺寸不变。

### R4：底部状态与版本识别

- 左下角在鼠标位于 axes 内时显示当前数据坐标，离开 axes 后回到紧凑产品/版本信息；
- linear/log 坐标均按正式 scale 反算，显示精度稳定，不把视图坐标误当数据坐标；
- 安装应用显示可核对的版本或构建修订，确保用户能确认正在运行本次替换后的应用。

完成条件：四个角、轴中心、缩放和平移后坐标均正确；安装包位置、版本和 Spotlight 唯一性可核对。

### R5：回归与人工验收

- 增加多文件颜色、列重绑、文件分组、星号输入、annotation 清空关闭删除、紧密对象 bounds、
  Publication Check 过滤和坐标反算测试；
- 运行格式检查、workspace tests、固定 Rust 1.98.0 Clippy `-D warnings` 和统一 B5P 审计；
- 用实际安装的 macOS 应用完成多文件与所有相关小窗的人工操作；
- 独立功能 QA 只报告可复现错误或明确优化点，不把一般代码审查代替产品操作验收；
- Windows 最大化/全屏行为保留为以后实机复核，不因缺少设备宣称通过。

## 5. 明确不在 B5R 扩张的范围

- 不连接或修改 Lite producer/launcher；
- 不进行 DMG/MSI/公证、商店或正式发布；
- 不重新开放字号、grid、朝外刻度、刻度线长宽等已冻结设置；
- 不增加多 axes、3D、完整 LaTeX 或通用矢量编辑器；
- 不因界面收尾改写已验证的字体、Display List、PDF/PNG 或项目格式原则。

## 6. 推荐执行顺序

1. R0 多文件导入、自动配色和文件栏；
2. R1 标签工具对齐、`\*`、标注删除语义与全部窗口排版；
3. R2 annotation/legend 紧密对象边界与图外画布；
4. R3 Publication Check 独立精简窗口；
5. R4 坐标状态和版本识别；
6. R5 自动回归、安装应用和人工验收。

所有条目完成后再讨论 Lite 联调或 B6 发布，期间不以新增功能替代上述收尾验收。

## 8. B5R.1 真实操作复核与修订（2026-09-25）

本轮以安装应用中的真实操作结果为准。此前标记“完成”的功能若在真实操作中复现异常，必须
重新打开并修复，不得仅凭已有单元测试判定通过。

### P0：图外图例后的画布交互闭环

- 副刻度固定间隔的数据模型和输入控件本身可用；已确认异常只在 legend 位于图上或图右后出现。
- 修复图外画布扩展后的命中坐标、对象优先级或窗口目标映射，使主刻度、副刻度、轴标签、曲线、
  标注和图例仍能准确双击编辑。
- 覆盖图内、图上、图右，缩放、滚动、图例拖动/改行列，以及普通、最大化、全屏窗口。
- 图例不得以虚大的矩形遮挡 axes 命中区域；位置改变后 hit map 必须立即随正式布局更新。

### P1：文件栏与导入默认样式

- 每个文件的 X、Y 下拉框改成上下两行并统一对齐，窄侧栏不得重叠或裁切。
- 每张文件卡始终保留可见、居中的删除 `×`；侧栏允许拖动，采用合理的默认、最小和最大宽度。
- 分批或一次导入多个独立文件时，默认颜色和 marker 都依次不同；同一数据族仍保持一致关系。

### P1：对象编辑与反馈

- 选中曲线时提供清晰但不污染导出的高亮，并同步突出该曲线对应的 legend key/entry。
- marker 尺寸和“每隔几点显示一次”提供一次可撤销的“应用到全部曲线”。
- legend label 使用与轴标签一致的语义标签链路，支持斜体、正体、上下标、希腊变量和数学符号，
  且画布、PDF/PNG、保存重开一致。
- Publication Check 的产品界面使用中文对象名、原因、影响和修改建议，不显示内部英文 ID；仍只展示
  error 和 warning。

### 相邻风险检查

- 检查图外图例状态下的数据坐标读数、选择框、拖拽框和导出紧边界。
- 检查多个独立编辑窗口与主窗口交互，确保点击主图不会关闭其他窗口，也不会将编辑提交给错误对象。
- 检查全屏/最大化时所有小窗可见、可移动、可找回，恢复普通窗口后状态不丢失。
