# InstPlot Studio 双轴 Phase 2 验收记录

日期：2026-09-27
分支：`codex/dual-axes`
范围：document/transaction 层模式切换、轴绑定、休眠可见性与独立自动范围。

## 完成内容

- `FigureDocument` 提供轴模式读取/切换、按稳定轴身份读取记录、逻辑曲线轴绑定读取/修改。
- `EditCommand` 增加模式切换和曲线轴绑定命令，完整进入现有撤销、重做和原子校验流程。
- 首次启用副轴时创建独立、稳定的 axis/label 身份；X2、Y2设置在模式切换后继续保留。
- 项目模型统一提供 artist 的数据轴绑定与有效可见性；持久 `visible` 不因副轴关闭而改变。
- 图例条目、正式 layout 输入、出版规范视觉编码和 UI 图例读取均使用有效可见性；标注连接线按自己的轴组合过滤。
- 自动范围按 X1、X2、Y1、Y2分别计算，且只读取当前有效可见的所属逻辑曲线。
- X/Y 误差棒的上下限完整参与对应轴范围；参考线按自身方向和轴组合参与；普通文字与连接目标不扩展范围。
- 无数据自动轴进入稳定空范围，后续布局阶段负责不为无数据副轴显示虚假刻度。
- 数据源删除、清空、导入刷新以及误差列修改统一刷新所有活动自动轴。
- 图例样式关联由旧的“相同数据绑定猜测”改为稳定逻辑曲线成员关系，避免重复绑定串组。
