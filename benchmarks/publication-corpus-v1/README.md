# Publication Visual Benchmark Corpus V1

This corpus records citations and derived observations, not copies of publisher
images. It supplies an A1 comparison envelope for figure geometry and visual
hierarchy while respecting uncertain redistribution rights.

The reference set covers Nature-family journals, a Science Partner Journal,
Physical Review Letters, JACS, and Advanced Materials/Wiley. Each entry is chosen
for one or more of the primary SciPlot patterns: two-dimensional curves, scatter,
error bars, fits, theory overlays, or repeated panels.

The numeric comparison ranges are calibration hypotheses, not product defaults.
A7 must render the fixed fixture, measure it at final physical size, compare it
against this corpus, and either confirm the ranges or revise them through an ADR.
No source image should be added to this directory without a recorded license that
permits redistribution.
